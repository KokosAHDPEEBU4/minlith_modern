# Контроль качества: невязка (defect) и детектор аномалий

## 1. Невязка (defect)

После прохождения всех трёх стадий у вас остаются финальные значения `n_ост(X)` для каждого оксида X. В идеальном случае все они равны нулю (кроме SiO₂, который целиком и осознанно уходит в кварц на последнем шаге — это не невязка, а нормальный результат).

```
defect(X) = n_ост(X) после всех стадий      # в молях или в вес.% эквиваленте
defect_total = Σ |defect(X) * M(X)|          # суммарная невязка в вес.%, по всем оксидам
```

Практический смысл: если `defect_total` мало (условно, единицы относительных % от суммы оксидов) — расчёт "сошёлся" нормально. Если велико — где-то либо:
- порода не подходит под предположения метода (например, сильно метаморфизована, или это не осадочная порода вообще);
- один из эмпирических коэффициентов (k1-k4, пороги типа породы) не подходит для этого конкретного состава;
- в анализе есть оксид/элемент, для которого в вашей реализации нет минерала-приёмника (например, Cr₂O₃, ZrO₂, BaO — редкие элементы, для которых в CIPW-подобных методах есть отдельные минералы: хромит, циркон, барит — стоит решить заранее, включать ли их).

**Рекомендация**: считайте и храните defect отдельно по каждому оксиду (не только суммарно) — это даёт возможность понять, *какая именно* группа минералов "виновата" в ошибке, что прямо соответствует вашему `result.defect` из README.

## 2. Детектор аномалий — общий принцип

Задача детектора — не пересчитать заново, а **проверить правдоподобность уже полученного результата** и указать, что именно выглядит подозрительно. Общий принцип для всех правил один: искать признаки того, что распределение оксидов пошло "не по тому сценарию" — либо получился **отрицательный минерал** (то есть на каком-то шаге было отдано больше оксида, чем реально доступно — это невозможно физически, значит, ошибка в порядке или коэффициентах), либо получилось **физически неправдоподобное количество** минерала (слишком много/мало относительно того, что ожидается для этого типа породы).

Судя по вашему README (10 правил: гипс, сумма, Fe, апатит, дефект, карбонат, полевой шпат, P, отрицательные минералы), логика каждого правила примерно такая:

| Правило | Что проверяет | Логика срабатывания |
|---|---|---|
| Отрицательные минералы | Любой n(минерал) < 0 | Прямой сигнал ошибки порядка/коэффициентов на предыдущем шаге — самое надёжное правило, не требует калибровки |
| Сумма | Σ вес.%(минералов) сильно отличается от 100% до нормировки | Большая расходимость → анализ некачественный или порода не подходит под метод |
| Дефект | defect_total выше порога (напр. >5-10 отн.%) | См. раздел 1 выше |
| Апатит | P₂O₅ значителен, но апатит около 0 или наоборот апатит непропорционально велик относительно исходного P₂O₅ | Признак ошибки в стадии 1 (например, весь P на самом деле не в апатите, а во вторичном фосфате) |
| P (фосфор отдельно) | P₂O₅ выше типичного для осадочных пород уровня (например, >0.3-0.5 вес.%) без геологического обоснования (фосфорит) | Предупреждение, а не ошибка — может быть фосфоритом, стоит пометить отдельно |
| Fe | Резкое несоответствие Fe₂O₃/FeO ожидаемому диапазону окисленности для типа породы, либо отрицательный магнетит/гематит | Сигнал, что нужно пересмотреть распределение Fe между оксидами/силикатами/карбонатами |
| Карбонат | Кальцит/доломит получаются отрицательными, либо сумма карбонатов превышает физически разумный предел (>95-100% для чисто карбонатных пород) | Проверка на некорректный выбор ветки "карбонатный тип" |
| Полевой шпат | Сумма Or+Ab+An превышает разумный для осадочной породы уровень (полевые шпаты редко >60-70% даже в очень зрелых аркозах) либо получаются отрицательными | Сигнал ошибки в стадии 2 |
| Гипс | Гипс появляется в породе без геологического контекста эвапорита (SO₃ мал, но гипс почему-то велик, или наоборот) | Проверка корректности стадии 1 |

**Важно:** конкретные числовые пороги ("выше 5%", "больше 60%") в таблице выше — это ориентировочные, разумные с точки зрения общей седиментологии значения, не выверенные по оригинальной статье. Их стоит либо взять из справочника по петрографии осадочных пород (диапазоны содержаний минералов по фациальным типам), либо подбирать эмпирически на своих тестовых примерах.

## 3. Как тестировать реализацию

Поскольку метод изначально эмпирический (не точная физика), тестировать стоит не на "теоретически идеальных" примерах, а на:
1. **Классических учебных составах** — типичный кварцевый песчаник, типичный аркоз, типичная глина/аргиллит, типичный известняк/доломит — такие таблицы легко найти в любом учебнике по петрографии осадочных пород. Ожидание: результат должен давать доминирование "правильного" минерала (кварц для песчаника, глинистые для аргиллита, карбонаты для известняка) — если нет, проблема в базовой логике, а не в тонкой калибровке.
2. **Граничных случаях** — состав с нулевым CaO (не должно быть анортита/кальцита), состав без CO₂ (карбонаты не должны считаться по прямому CO₂-балансу), состав с очень малым Al₂O₃ (не должно быть избыточных глинистых минералов) — это хорошие unit-тесты именно на "не сломался ли баланс".
3. **Property-based тестах** (раз у вас уже используется Hypothesis) — полезное инвариантное свойство: **сумма всех минералов (в вес.%, до финальной нормировки на 100%) не должна давать отрицательных компонентов**, и **невязка по каждому оксиду не должна превышать сам оксид** (то есть нельзя "перерасходовать" больше, чем было). Это чисто математические инварианты, не зависящие от геологической специфики — их стоит проверять всегда, вне зависимости от того, откалиброваны ли у вас k-коэффициенты точно как в оригинале.
