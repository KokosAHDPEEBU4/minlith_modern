**Важная оговорка сразу.** Это не точное воспроизведение проприетарного алгоритма MINLITH Розена и Аббясова "бит в бит" — точные числовые пороги ветвления и коэффициенты k1-k4 находятся в оригинальных статьях (Rosen, Abbyasov, Tipper, 2004, Computers & Geosciences, т. 30, №6; Розен, Аббясов, 2003, Литология и полезные ископаемые, №3), доступа к полному тексту которых у меня нет. То, что изложено ниже — это:
1. **Строго проверенная общая теория** нормативного минералогического расчёта (стехиометрия, метод последовательного вычитания оксидов) — это стандартная петрохимия, здесь ошибиться сложно.
2. **Принципиальная структура алгоритма MINLITH** (3 стадии, список минеральных групп) — подтверждено аннотациями оригинальных статей.
3. **Практические эмпирические решения** (пороги для классификации типов пород, конкретные значения k-коэффициентов) — это моя реконструкция по аналогии со стандартными методами (CIPW и родственные), которую нужно будет откалибровать на реальных данных. Такие места отмечены явно словом "ТРЕБУЕТ КАЛИБРОВКИ".

## 1. Зачем вообще нужен нормативный расчёт

Задача: есть валовый химический анализ породы (вес.% оксидов — SiO₂, TiO₂, Al₂O₃, Fe₂O₃, FeO, MgO, CaO, Na₂O, K₂O, P₂O₅, MnO, SO₃, F, Cl, S, CO₂ и т.д.). Нужно оценить, из каких минералов и в каких количествах (вес.%) состоит порода, не имея под рукой петрографического шлифа или рентгенограммы.

Метод: **последовательное распределение (allocation) каждого оксида по минералам**, в порядке от самых однозначных (маркерных) минералов к самым "неопределённым" (тем, что забирают остаток). Это стандартный подход, использующийся, например, в CIPW-норме для магматических пород, и MINLITH применяет ту же логику, но с другим набором минералов, подходящим для осадочных пород, и с эмпирически откалиброванными правилами вместо строгой термодинамики.

## 2. Базовая математика: от весовых % к молям и обратно

### 2.1. Оксид → моли

```
n(оксид_i) = (вес.% оксида_i) / M(оксид_i)
```

где `M` — молярная масса оксида. Все дальнейшие балансовые действия ведутся **в молях** (или, что то же самое, в "молекулярных пропорциях" — общепринятый термин в этой области).

### 2.2. Минерал определяется как фиксированная комбинация оксидов

Каждый нормативный минерал в таких расчётах представляется не через "истинную" кристаллохимическую формулу, а через удобную для баланса **оксид-молекулярную запись**. Пример: ортоклаз KAlSi₃O₈ в оксид-молекулярной записи — `(K₂O)(Al₂O₃)(SiO₂)₆` (то есть 1 моль K₂O + 1 моль Al₂O₃ + 6 моль SiO₂ образуют 1 "формульную единицу" ортоклаза). Это не изменяет стехиометрию, просто удобная бухгалтерия для программной реализации.

**Общий алгоритм для одного минерала, определяемого как `(A)(B)a(C)c...`:**

```
n(минерал) = min( n(A), n(B)/a, n(C)/c, ... )   # если минерал — "финальный получатель" одного оксида
```

Но в подавляющем большинстве случаев в норме каждый оксид закреплён ровно за одним минералом на каждом шаге (это и есть суть метода последовательного вычитания — конкуренции разрешаются порядком шагов, а не через min()). Тогда:

```
n(минерал) = n(оксид_ведущий) / (коэффициент оксида_ведущего в формуле)
```//
и затем **вычитаются** количества всех прочих оксидов, входящих в этот минерал, из их "остаточных" пулов:

```
n_ост(B) = n_ост(B) - c_B * n(минерал)
```

где `c_B` — мольный коэффициент оксида B в формуле минерала.

### 2.3. Моли минерала → вес.%

```
масса(минерал) = n(минерал) * M_формула(минерал)
```

где `M_формула` — сумма молярных масс всех оксидов в оксид-молекулярной записи минерала (с их коэффициентами). После расчёта всех минералов вес.% каждого:

```
вес.%(минерал) = 100 * масса(минерал) / Σ масса(всех минералов)
```

(нормировка нужна, потому что исходная сумма оксидов редко равна ровно 100%, а после аллокации накапливаются небольшие ошибки округления).

### 2.4. Невязка (residual / defect)

Для контроля качества на каждом шаге и в конце считается **невязка** — сколько оксида осталось "неучтённым":

```
defect(оксид_i) = n_ост(оксид_i)   # то, что не удалось пристроить ни в один минерал
```

В идеале в конце расчёта defect по каждому оксиду близок к нулю (кроме SiO₂, чей остаток целиком уходит в кварц — это не invalid, а последний, "закрывающий" шаг).

## 4. Общая структура алгоритма (три стадии MINLITH)

```
Вход: вес.% всех оксидов пробы
  │
  ├─ Шаг 0: пересчёт вес.% → моли всех оксидов, создание "остаточных пулов" n_ост(X) = n(X)
  │
  ├─ Стадия 1: второстепенные минералы
  │     апатит → пирит → гипс → флюорит → галит
  │     (см. 01_stage1_minor_minerals.md)
  │
  ├─ Классификация типа породы (1-5) по остаточным Al₂O₃, щелочам, CaO
  │     (см. 02_stage2_aluminous_minerals_rock_types.md, раздел "Типы пород")
  │
  ├─ Стадия 2: алюмосодержащие минералы
  │     полевые шпаты (Or, Ab, An) → глинистые минералы/слюды → гиббсит
  │     (см. 02_stage2_aluminous_minerals_rock_types.md)
  │
  ├─ Стадия 3: остаточные минералы
  │     карбонаты (кальцит/доломит/сидерит) → оксиды (Ti, Fe) → свободный кварц
  │     (см. 03_stage3_residual_minerals.md)
  │
  ├─ Пересчёт молей всех минералов → вес.%, нормировка на 100%
  │
  └─ QC: расчёт defect по каждому оксиду, прогон правил AnomalyDetector
        (см. 04_qc_defect_anomalies.md)
```

Каждая стадия описана в отдельном файле с явными формулами и порядком шагов — этого достаточно, чтобы формализовать в виде функций/веток кода без необходимости понимать геологию "по наитию".
