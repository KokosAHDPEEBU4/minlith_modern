### 4.2. Назначение

### 5.3. Особенности перевода

**SiO₂ (строка 2):**
```
D2 = ROUND(B2*10000/C2, 0)
   = ROUND(52.5*10000/60.09, 0)
   = ROUND(8736.89, 0)
   = 8737
```
Округление до ЦЕЛОГО.

**FeO (строка 6):**
```
D6 = ROUND((B5*0.9+B6)*10000/C6, 0)
   = ROUND((1.71*0.9 + 8.06)*10000/71.85, 0)
   = ROUND((1.539 + 8.06)*10000/71.85, 0)
   = ROUND(9.599*10000/71.85, 0)
   = ROUND(1335.98, 0)
   = 1336
```
Fe₂O₃ переводится в FeO-эквивалент (×0.9) и складывается с FeO.

**CaO (строка 8):**
```
D8 = ROUND(B8*10000/C8,0) - ROUND(3.33*B11/C11*10000 + B15/C15*10000/2, 0)
```
Вычитание Ca из апатита (3.33×P₂O₅) и флюорита (F/2).

**Na₂O (строка 9):**
```
D9 = ROUND(B9*10000/C9,2) - ROUND(B16/C16/2*10000,2)
```
Вычитание Na из галита (Cl/2).

### 5.6. Расчёт Type 1 (Строки 43-...)

**Базовые назначения:**
```
Ab = Na° = 151.66
Or = K° = 366.24
Si1 = Si° - 6×Ab = 8737 - 6×151.66 = 7827.04
Al1 = Al° - Or - Ab = 2296 - 366.24 - 151.66 = 1778.1
```

**Распределение An (анортит):**
```
Если Al1 ≤ Ca1:  # 1778.1 ≤ -23? НЕТ
    → переход к 1.2

1.2: Al1 > Ca1
    Если Si2 ≥ 2×Ca1:  # 7827.04 ≥ 2×(-23)? ДА
        An = Ca1 = -23  # ???

Примечание: Отрицательный Ca1 указывает на дефицит Ca после вычета апатита.
```

**Дальнейшее ветвление:** См. полный trace в debug-режиме.

### 5.7. Расчёт Type 2

Аналогичен Type 1 с дополнительными ветвлениями для Ill (иллит).

### 5.8. Этап VI — Финальное распределение

**Остатки после распределения:**
```
Ca_n = Ca° - Ca_в_минералах
Mg_n = Mg° - Mg_в_минералах
Fe_n = Fe° - Fe_в_минералах
Mn_n = Mn° - Mn_в_минералах
Si_n = Si° - Si_в_минералах
```

**Ветвление:**
```
Если Ca_n ≥ Mg_n + Fe_n:
    → VI А: Dl = Mg_n, Ank = Fe_n, Cc = Ca_n - Dl - Ank
Иначе:
    → VI Б: проверка Ca_n vs Mg_n
        Если Ca_n < Mg_n:
            → VI B: Dl = Ca_n, Mg_n1 = Mg_n - Dl
                Если Si_n ≥ 2/3 × Mg_n1:
                    → Srp = Mg_n1/3, Q = Si_n - 2×Srp
                Иначе:
                    → Srp = Si_n/2, Mst = Mg_n1 - 3×Srp
```

### 5.9. Этап VII — Перевод в вес.%

```
вес.%_минерала = ф.е._минерала × формульный_вес / 10000
```

**Пример для T-O2:**
```
Ab: 151.66 ф.е. × 524.482 / 10000 = 7.954% → округлено 7.82%
Ill: 183.12 ф.е. × 2014.75 / 10000 = 36.894% → округлено 36.26%
```

**Примечание:** Расхождение из-за промежуточных округлений в Excel.

## 6. ЛИСТ "Нач+Type 3" — РАСЧЁТ TYPE 3

### 6.1. Структура

Аналогичен "Нач+Type 12", но:
- Более сложное ветвление (~300+ строк)
- Дополнительные переменные: Chl (хлорит), Ill (иллит)
- Больше условий перехода (goto)

### 6.2. Ключевые отличия от Type 1-2

- Распределение Al между Or, An, Chl, Ill, Kn, Gb
- Проверка избытка/дефицита Mg и Fe
- Больше промежуточных переменных (Al1, Al2, Al3, Al4, Si1, Si2, Si3, Si4...)

### 6.3. Пример ветвления (строки 30-100)

```
3.1: Ab = Na°
     Si1 = Si° - 6×Ab
     Al1 = Al° - Ab

3.1.1: Если Ca1 ≥ 0.2×Na° И Si1 < 6×K° + 0.4×Na°
           → An = 0.2×Na°, переход к 3.3.1
       Иначе если Ca1 < 0.2×Na° И Si1 < 6×K° + 2×Ca1
           → An = Ca1, переход к 3.3.1
       Иначе
           → Or = K°, далее ветвление по Al

3.3.1: Распределение Or, Ill, Chl
       Если 2×Al3 ≥ Si3:
           → Kn = Si3/2, Gb = Al3 - Kn, Si4 = 0
       Иначе:
           → Kn = Al3, Si4 = Si3 - 2×Kn
```

**Примечание:** Полное воспроизведение требует пошагового trace для конкретного образца.

## 8. ОСОБЕННОСТИ EXCEL4-СТИЛЯ

### 8.1. Формулы

| Функция | Использование | Примечание |
|---------|-------------|------------|

### 8.2. Проблемы точности

| Проблема | Пример | Решение |
|----------|--------|---------|
| Float артефакты | 0.9194100000000001 | Округлять при чтении |

| Округление промежуточных | ROUND после каждого шага | Может накапливаться ошибка |
| Разделитель | Точка (.) vs запятая (,) | Зависит от локали |

### 8.3. GOTO-метки

В формулах используются текстовые метки перехода:
- "goto 3.2.1,"
- "else goto 3.2.2,"
- "переход к VI Этапу"

**Это НЕ настоящий GOTO Excel**, а комментарии для пользователя. Фактически — вложенные IF.

## 10. РЕКОМЕНДАЦИИ ПО ВОСПРОИЗВЕДЕНИЮ

### 10.1. Приоритеты

1. **Точность алгоритма** — результат должен совпадать с оригиналом ±0.01%
2. **Скорость** — векторизация + параллельность
3. **Надёжность** — обработка ошибок, валидация
4. **Удобство** — GUI, отчёты, диаграммы

### 10.2. Тестовые данные

| Образец | Тип | Особенности |
|---------|-----|-------------|
| БК-1 | 3 (?) | Высокое Na₂O+K₂O, низкий MgO |
| T-O2 | 1 | Средний состав, отрицательный CaO после коррекции |
| Чистый SiO₂ | — | Q = 100% |
| Чистый CaCO₃ | — | Cc = 100% |
| Граница Type 1-2 | — | Al = 1.2Na + K |
| Граница Type 2-3 | — | Al = 1.2Na + 3.25K |

### 10.3. Отладка

Для каждого образца сохранять:
- Все промежуточные переменные (Al1, Al2, Si1, Si2...)
- Условия ветвления (истина/ложь)
- Переходы между блоками
- Итоговые формульные единицы и вес.%
