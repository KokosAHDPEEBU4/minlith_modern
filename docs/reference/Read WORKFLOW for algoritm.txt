### SECTION 1: STAGE 0 -- PREPARATION (Formula Unit Conversion)

**From EXCEL_REFERENCE_MINLITH.md, Section 5.2 + 5.3 + Appendix A:**

```
Stage 0: Convert weight.% to formula units (f.u.)
=================================================

General formula:
  ф.е. = weight.% / molar_mass * 10000

Specific oxide conversions (from Excel sheet "Нач+Type 12"):

SiO2 (row 2):
  D2 = ROUND(B2*10000/C2, 0)
  Example: ROUND(52.5*10000/60.09, 0) = ROUND(8736.89, 0) = 8737
  NOTE: Rounded to INTEGER.

TiO2 (row 3):
  D3 = B3  (weight.% = f.u. directly)

Al2O3 (row 4):
  D4 = ROUND(B4*10000/C4, 0)   [where C4 = 101.96 molar mass]

Fe2O3 -> FeO conversion (row 6):
  D6 = ROUND((B5*0.9+B6)*10000/C6, 0)   [where C6 = 71.85]
  Fe2O3 is converted to FeO-equivalent by multiplying by 0.9, 
  then added to the actual FeO value.
  Example: ROUND((1.71*0.9 + 8.06)*10000/71.85, 0) = ROUND(9.599*10000/71.85, 0) = 1336

MgO (row 7):
  D7 = ROUND(B7*10000/C7, 0)   [where C7 = 40.32]

CaO -- APATITE CORRECTION (row 8):
  D8 = ROUND(B8*10000/C8, 0) - ROUND(3.33*B11/C11*10000 + B15/C15*10000/2, 0)
  
  This means:
    CaO_corrected = CaO_raw(f.u.) - (3.33 * P2O5_f.u. + F_f.u./2)
    
  Where:
    - 3.33 * P2O5 = Ca consumed by apatite Ca5(PO4)3(F,Cl,OH)
      (5 Ca per 3 P = 5/3 = 1.667, but formula uses 3.33 because 
       P2O5 contains 2 P atoms, so 5 Ca / (3/2 P2O5) = 10/3 = 3.33)
    - F/2 = Ca consumed by fluorite CaF2
      (1 Ca per 2 F atoms)

Na2O -- HALITE CORRECTION (row 9):
  D9 = ROUND(B9*10000/C9, 2) - ROUND(B16/C16/2*10000, 2)   [where C9=61.982, C16=35.457]
  
  This means:
    Na2O_corrected = Na2O_raw(f.u.) - Cl/2
    Na consumed by halite NaCl: 1 Na per 1 Cl = Cl/2 Na2O units

K2O (row 10):
  D10 = ROUND(B10*10000/C10, 2)   [where C10 = 94.2]

P2O5 (row 11):
  D11 = ROUND(B11*10000/C11, 2)   [where C11 = 141.95]

MnO (row 12):
  D12 = ROUND(B12*10000/C12, 2)   [where C12 = 70.94]

C (row 13):
  D13 = B13   (weight.% = f.u. directly)

SO3 (row 14):
  D14 = ROUND(B14/C14*10000, 2)   [where C14 = 80.066]

F -- FLUORITE CORRECTION (row 15):
  D15 = ROUND(B15/C15*10000, 2) - 0.67*D11
  
  This means:
    F_corrected = F_raw(f.u.) - 0.67 * P2O5_f.u.
    F consumed by apatite: 1 F per 3 P2O5 units... but the formula 
    shows 0.67 * P2O5, not 0.33 * P2O5. This implies:
    - Ap = Ca5(PO4)3F => 1F per 3P, but P2O5 has 2P, so 
      F/P2O5 = 1/1.5 = 0.667 ≈ 0.67

Cl (row 16):
  D16 = ROUND(B16/C16*10000, 2)   [where C16 = 35.457]

S (row 17):
  D17 = ROUND(B17/C17*10000 + D14, 2)   [S f.u. + SO3 f.u.]

CO2 (row 18):
  D18 = ROUND(B18/C18*10000, 2)   [where C18 = 44.011]

SO (row 19):
  D19 = ROUND(B19/C19*10000, 0)   [rounded to INTEGER]
```

**From EXCEL_REFERENCE_MINLITH.md, Section 5.4 + TZ Appendix V:**

F = Fe3+ / Sigma(Fe)   (row 2, column H)

A = Al / (Al + Fe)   (row 2, column J)

k1-k4 formulas by F range (all rounded to 3 decimal places in Excel):
=============================================================

| F Range    | k1                    | k2                    | k3                         | k4              |
|------------|-----------------------|-----------------------|----------------------------|-----------------|
| 0 -- 0.21  | -5.18*F + 4.42        | 4.09*F                | (3.16 - 0.41*F) / 2       | 10 - k1-k2-2k3  |

| 0.69 -- 0.87 | 6.2 - 12*F          | 2.54*F + 1.24         | (3.46*F + 0.53) / 2       | 10 - k1-k2-2k3  |

### SECTION 4: TYPE 1 CALCULATION

**From EXCEL_REFERENCE_MINLITH.md Section 5.6 + MINERAL_CHEMISTRY.md Section 4.3:**

```
TYPE 1 DISTRIBUTION LOGIC:
==========================

Step 1: Assign feldspars
  Ab = Na   (all sodium goes to albite)
  Or = K    (all potassium goes to orthoclase)

Step 2: Calculate remaining Si and Al
  Si1 = Si - 6*Ab   (each Ab consumes 3 Si, but formula shows 6?)
  Al1 = Al - Or - Ab  (each Or consumes 1 Al, each Ab consumes 1 Al)

  NOTE: The "6*Ab" likely comes from the fact that the formula unit 
  calculations work differently than the simple stoichiometry suggests.
  From the example: Si1 = 8737 - 6*151.66 = 7827.04
  This means 6 Si units per Ab formula unit. But Ab = NaAlSi3O8 has 3 Si.
  The factor 6 may relate to how f.u. are calculated (dividing by molar mass).

Step 3: Distribute An (anorthite)
  IF Al1 <= Ca1:
      -> go to branch 1.2 (labeled in Excel)
  
  Branch 1.2 (Al1 > Ca1):
      IF Si2 >= 2*Ca1:
          An = Ca1   (all Ca goes to anorthite)
      ELSE:
          An = Si2/2
          Si3 = 0

  CRITICAL EDGE CASE: If Ca1 is NEGATIVE (as in T-O2 where Ca1 = -23):
      Al1 (1778) > Ca1 (-23): TRUE
      Si2 (7827) >= 2*Ca1 (-46): TRUE
      An = Ca1 = -23   (NEGATIVE anorthite! This is an artifact.)

Step 4: Distribute Al between Kn (kaolinite) and Gb (gibbsite)
  Al2 = Al1 - An
  Si3 = Si2 - 2*An   (each An consumes 2 Si)
  
  IF 2*Al2 >= Si3:
      Kn = Si3/2
      Gb = Al2 - Kn
      Si4 = 0
  ELSE:
      Kn = Al2
      Si4 = Si3 - 2*Kn

Step 5: Quartz from remaining Si
  Q = Si4

EXAMPLE (T-O2, simplified):
  Ab = 151.66
  Or = 366.24
  Si1 = 8737 - 6*151.66 = 7827
  Al1 = 2296 - 366.24 - 151.66 = 1778

  Al1 (1778) > Ca1 (-23): YES
  Si2 (7827) >= 2*Ca1 (-46): YES
  An = Ca1 = -23  (negative!)

  Al2 = 1778 - (-23) = 1801
  Si3 = 7827 - 2*(-23) = 7873

  2*Al2 (3602) >= Si3 (7873)? NO
  Kn = Al2 = 1801
  Si4 = 7873 - 2*1801 = 4271

  Q = Si4 = 4271

  NOTE: This is the simplified version. The actual Excel trace for T-O2 
  produces different final values (Q=5313.84, Ill=183.12, Chl=383.27, 
  Kn=-385.09) because additional branching occurs with illite and chlorite 
  distribution that is not fully captured here. The full trace requires 
  >50 steps.
```

### SECTION 8: STAGE VI -- FINAL DISTRIBUTION OF RESIDUALS

**From EXCEL_REFERENCE_MINLITH.md Section 5.8 + MINERAL_CHEMISTRY.md Section 4.4:**

```
STAGE VI -- FINAL DISTRIBUTION OF RESIDUALS:
=============================================

After Type 1-5 distribution, calculate residuals:
  Ca_n = Ca - Ca_in_minerals
  Mg_n = Mg - Mg_in_minerals
  Fe_n = Fe - Fe_in_minerals
  Mn_n = Mn - Mn_in_minerals
  Si_n = Si - Si_in_minerals

BRANCHING LOGIC:
================

BRANCH VI-A: IF Ca_n >= Mg_n + Fe_n
--------------------------------------------------
  This means Ca is sufficient to accommodate all Mg and Fe as carbonates.

  Dl (dolomite) = Mg_n       (CaMg(CO3)2 -- takes all Mg)
  Ank (ankerite) = Fe_n      (Ca(Fe,Mg)(CO3)2 -- takes all Fe)
  Cc (calcite) = Ca_n - Dl - Ank   (remaining Ca goes to calcite)
  Rch (rhodochrosite) = Mn_n
  Q (quartz) = Si_n

  SUB-BRANCH for Fe distribution:
    IF Ca_n (after Dl and Ank) <= 250 f.u.:
        Ht (hematite) = Fe_n / 2
    ELSE:
        Sd (siderite) = Fe_n

BRANCH VI-B: IF Ca_n < Mg_n + Fe_n
--------------------------------------------------
  Ca is NOT sufficient for all Mg and Fe.

  SUB-BRANCH: IF Ca_n < Mg_n
  ------------------------------------------
    Dl (dolomite) = Ca_n       (all Ca goes to dolomite)
    Mg_n1 = Mg_n - Dl          (remaining Mg after dolomite)

    SUB-SUB-BRANCH: IF Si_n >= 2/3 * Mg_n1
    ------------------------------------------
      Srp (serpentine) = Mg_n1 / 3
      Q (quartz) = Si_n - 2*Srp

    ELSE (Si_n < 2/3 * Mg_n1):
      ------------------------------------------
      Srp (serpentine) = Si_n / 2
      Mst (magnesite) = Mg_n1 - 3*Srp

  Ht (hematite) = Fe_n / 2    (or Sd = Fe_n)
  Prl (pyrolusite) = Mn_n

NOTE: The 250 f.u. threshold for Ca_n1 is an empirical constant 
from the original MINLITH algorithm. It determines whether iron 
goes to hematite (Fe2O3) or siderite (FeCO3).
```

### SECTION 9: CA CORRECTION (APATITE) -- DETAILED

**From EXCEL_REFERENCE_MINLITH.md Section 5.3 + MINERAL_CHEMISTRY.md Section 3.1:**

```
CA CORRECTION FOR APATITE:
==========================

Apatite formula: Ca5(PO4)3(F,Cl,OH)
Formula weight: 336.21

Per formula unit of apatite:
  - Consumes 5 Ca
  - Consumes 3 P
  - Consumes 1 F (or Cl/OH, but in MINLITH we account for F separately)

Since P is measured as P2O5:
  P2O5 has 2 P atoms per formula unit
  So 3 P = 1.5 P2O5
  Ca per P2O5 = 5/1.5 = 3.33

Therefore: Ca consumed by apatite = 3.33 * P2O5_f.u.

The correction in the formula:
  D8 = ROUND(B8*10000/C8, 0) - ROUND(3.33*B11/C11*10000 + B15/C15*10000/2, 0)

  CaO_corrected = CaO_raw(f.u.) - Ca_in_apatite - Ca_in_fluorite

  Ca_in_apatite = 3.33 * P2O5(f.u.)
  Ca_in_fluorite = F(f.u.) / 2   (CaF2: 1 Ca per 2 F)

EXAMPLE for T-O2:
  CaO = 0.28 wt%
  CaO_raw(f.u.) = 0.28/56.08*10000 = 50 f.u.
  P2O5 = 0.31 wt% -> P2O5_f.u. = 0.31/141.95*10000 = 22 f.u.
  F = 0 -> F_f.u. = 0
  
  Ca_in_apatite = 3.33 * 22 = 73.26 f.u.
  Ca_in_fluorite = 0/2 = 0

  CaO_corrected = 50 - 73.26 - 0 = -23 f.u.   (NEGATIVE!)

This means: The CaO content in the rock (0.28%) is INSUFFICIENT 
to form all the apatite required by the P2O5 content (0.31%).
The Ca correction produces a NEGATIVE Ca value.
```

### SECTION 10: ANORTHITE DISTRIBUTION WHEN CA IS NEGATIVE

**From EXCEL_REFERENCE_MINLITH.md Section 5.6 + MINERAL_CHEMISTRY.md Section 5.4:**

```
ANORTHITE DISTRIBUTION WITH NEGATIVE Ca:
=========================================

When Ca1 (Ca after apatite/fluorite correction) is negative:

In Type 1 logic:
  Al1 (1778) > Ca1 (-23)  -> TRUE (always true when Ca is negative)
  Si2 (7827) >= 2*Ca1 (-46) -> TRUE (always true when Ca is negative)
  An = Ca1 = -23  (NEGATIVE anorthite)

This creates a NEGATIVE anorthite value. Then:
  Al2 = Al1 - An = 1778 - (-23) = 1801
  Si3 = Si2 - 2*An = 7827 - 2*(-23) = 7873

The negative Ca "gives back" Al and Si to the pool, 
which then flows into other minerals (Kn, Gb, Q, etc.).

This is a KNOWN ARTIFACT of the algorithm:
  "The algorithm 'redistributes' elements, creating negative minerals."
  
  From EXCEL_REFERENCE Section 11:
  | Problem           | Manifestation            | Solution in new version           |
  |-------------------|--------------------------|------------------------------------|
  | Negative minerals | Kn = -9.77, Dl = -0.42   | Keep as-is, mark with warning      |
  | Sum > 100%        | 101.748%                 | Normalize to 100%, show original   |
```

### SECTION 12: EDGE CASES AND KNOWN PROBLEMS

**From EXCEL_REFERENCE_MINLITH.md Section 11 + MINERAL_CHEMISTRY.md Section 7 + TEST_CASES.md:**

```
KNOWN PROBLEMS / EDGE CASES:
=============================

1. NEGATIVE MINERALS
   Problem: Calculation can produce negative values (Kn = -9.77, Dl = -0.42)
   Cause: Sequential distribution can "over-allocate" elements on one step,
          leaving negative residuals for the next step.
   Solution in MINLITH: Keep negative values as-is, mark with warning.
   Do NOT zero them out (this changes the mass balance).

2. SUM > 100% (BEFORE NORMALIZATION)
   Example: T-O2 sum = 101.748%
   Solution: Normalize to 100%, but display original sum.
   Warning: Displayed when sum < 98% or sum > 102%.

3. FLOAT ARTIFACTS
   Example: Fe2O3 = 0.9194100000000001 (Excel precision artifact)
   Solution: Round on input to reasonable precision.

4. INTERMEDIATE ROUNDING
   Excel performs ROUND() after each step. This can accumulate error.
   New version: Use float64 internally, round only on output.

5. OPERATION ORDER
   Excel evaluates formulas left-to-right.
   Python uses standard operator precedence.
   This can cause subtle differences.

6. NEGATIVE CA AFTER APATITE CORRECTION
   When P2O5 is high relative to CaO, the apatite correction
   makes Ca negative. This flows through to negative An (anorthite).
   The algorithm handles this by using the negative value in 
   subsequent calculations (it "returns" Ca/Al/Si to the pool).

7. PURE MINERAL TEST CASES
   | Test | Input | Expected | Check |
   |------|-------|----------|-------|
   | Pure quartz | SiO2=100% | Q=100% | Sum=100% |
   | Pure calcite | CaO=56%, CO2=44% | Cc=100% | Sum=100% |
   | Pure albite | SiO2=68.7, Al2O3=19.5, Na2O=11.8 | Ab=100% | Sum~100% |
   | Pure orthoclase | SiO2=64.8, Al2O3=18.3, K2O=16.9 | Or=100% | Sum~100% |

8. BOUNDARY CONDITIONS BETWEEN TYPES
   | Boundary | Condition | Notes |
   |----------|-----------|-------|
   | Type 1-2 | Al = 1.2Na + K | Verify against original |
   | Type 2-3 | Al = 1.2Na + 3.25K | Verify against original |
   | Type 3-4 | Al = 5Na + 3.25K + (Mg-0.5K-2Na)*k3/k1 | Verify |
   | Type 4-5 | Al > threshold | Verify |

9. HIGH P2O5 (MANY APATITES)
   When P2O5 is very high, Ca correction makes Ca very negative.
   All Ca goes to apatite, none left for anorthite or carbonates.

10. HIGH F (MANY FLUORITES)
    When F is high, both Ca and F are consumed by fluorite.
    Double correction on Ca (from apatite AND fluorite).

11. GOTO-STYLE LABELS IN EXCEL
    The original uses text labels like "goto 3.2.1," and "else goto 3.2.2,"
    These are NOT actual GOTO commands -- they are user comments.
    The actual logic is implemented as nested IF statements.
```

```
CHLORITE (Chl) -- ADAPTIVE MINERAL:
====================================

Formula: (Mg,Fe)5Al(AlSi3O10)(OH)8
Formula weight: 683.396

Chl composition depends on k1-k4:
  k1 = Mg in chlorite (per formula unit)
  k2 = Fe in chlorite
  k3 = Al in chlorite
  k4 = Si in chlorite

Constraint: k1 + k2 + 2*k3 + k4 = 10  (sum of cations)

Example at F = 0.696:
  k1 = 1.427, k2 = 3.008, k3 = 1.469, k4 = 2.627
  Check: 1.427 + 3.008 + 2*1.469 + 2.627 = 9.999 ≈ 10

Physical meaning:
  F = 0 (all Fe2+):  Magnesian chlorite, high Mg
  F = 1 (all Fe3+):  Ferric chlorite, high Fe3+
  F = 0.5:           Transitional composition
```
