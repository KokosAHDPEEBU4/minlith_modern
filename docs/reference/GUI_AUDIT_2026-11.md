# Аудит визуала GUI (2026-11)

**Окно:** 1500 × 950, Windows, Segoe UI 13 px. Проверялись все страницы:
Начало, Файлы, Ввод, Результаты, Диаграммы, Вывод, Отчёты, История,
Настройки, Граф, Журнал. Метод: offscreen-скриншоты + программный обход
layout'ов (`contentsMargins`, `spacing`, `sizeHint`, реальные размеры виджетов).

## Остаточные точки роста

1. **Настройки** — собственная сетка (24/28 px) и собственный QSS; можно
   свести к общим токенам, но страница уже визуально цельная.
2. **Отчёты** — белый HTML-предпросмотр намеренно контрастирует с тёмной темой;
   можно добавить рамку/тень вокруг preview.
3. **Вкладки диаграмм** — системный красный крестик закрытия; при желании
   заменить на нейтральную иконку `×`.
4. **Эмодзи в сайдбаре** — разная ширина глифов; для идеального выравнивания
   нужен icon-set (SVG) вместо эмодзи.
5. **Тёмная/светлая тема** — QSS синхронизирован вручную; при добавлении новых
   контролов нужно дублировать правила в `default.qss` и `light.qss`.

|---|---|---|

| Вкладки | 20 / 1298 | 103 / 34 |
| MultiChartView | 21 / 1298 | 133 / 736 |

| Зазор панель → сетка | 6 px | — |
| Сетка диаграмм | 587 / 722 | 207 / 662 |
| Плитка (2 колонки) | 355 px | min 440 |
| Зазор между плитками | 8 px | — |
| Колонки выбора: диаграммы / образцы / минералы | 200 / 168 / 170 | — |
| Зазоры между колонками | 6 px | — |

Итог: при двух колонках 2×355 + 8 = 718 px помещается в 722 px viewport,
горизонтальная прокрутка отсутствует. Канвас диаграммы ограничен и по ширине,
и по высоте плитки, поэтому оси и подписи не обрезаются.
