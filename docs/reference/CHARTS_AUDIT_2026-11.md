# Аудит диаграмм MINLITH Modern (2026-11)

> **Исторический снимок.** Аудит проведён до перехода на осадочный набор:
> тогда было 23 matplotlib-плагина и 14 Plotly-диаграмм, включая QAPF, TAS,
> AFM, Харкера и другие магматические классификации. Позже они удалены
> (см. `CHARTS_SEDIMENTARY.md`); числа и разделы ниже относятся к версии до
> удаления и не описывают текущий набор.

**Область:** 23 matplotlib-плагина (`src/charts/built_in/`) и 14 интерактивных
Plotly-диаграмм (`src/charts/engines/plotly_charts.py`).

**Метод:** прогон всех диаграмм на 12 реальных образцах
(`docs/reference/parity_check/input_85_samples.xlsx`), визуальная проверка
рендеров, сверка формул с классическими определениями, тесты на геометрию
(`tests/test_chart_geometry.py`).

## Найденные и исправленные ошибки

| Диаграмма | Что было не так | Исправление |
|---|---|---|
| QAPF | Проекция перепутывала Q и A: Q не был вершиной, точки уходили к левому ребру. Полигоны полей не рисовались. | Общая тернарная проекция (`src/charts/ternary.py`); Q — верх, A — левый, P — правый; сетка Q = 5/20/60/90 %, A/(A+P) = 10/35/65/90 %; подписи полей. |
| Feldspar triangle | Та же ошибка проекции (Ab/An/Or), из-за чего плагиоклазы шли по левому ребру. | Ab — левый, An — правый, Or — верх; сетка An/(Ab+An) = 10/30/50/70/90 %. |
| AFM | Вырожденная диаграмма: при A+F+M=100 точки лежали на прямой `F+M=100−A`. | Полноценный треугольник A–F–M (A верх, F слева, M справа), схематичная граница Irvine & Baragar. |
| Mg-Fe-Al | Проекция не совпадала с подписями вершин; использовались весовые %, а не катионные пропорции. | Al верх, Fe слева, Mg справа; катионные пропорции; `requires_minerals=False` (данные — оксиды). |
| TAS | Образцы с SiO₂ > 80 % обрезались; поля без подписей. | Диапазон осей расширяется по данным; подписи полей; явная пометка «схема». |
| SiO₂–K₂O | Прямые линии с произвольным наклоном вместо границ серий. | Кусочно-линейные границы Peccerillo & Taylor (low/medium/high-K, шошонит). |
| A-CN-K | CaO* = CaO без поправки на карбонат/апатит; не было ориентиров. | `CaO* = min(CaO−CO₂−10/3·P₂O₅, Na₂O)`; подписи CIA 50–90; идеальные Pl, Kfs, Ill/Ms, Ka/Gb и стрелка выветривания (matplotlib + Plotly). |
| KF (k1–k4 vs F) | Дублирующиеся оси (`create_figure` + `add_subplot`), по X — индекс образца. | Одна ось; по X — F; нанесены точки образцов. |
| Pie / Radar / Rock type | Лишние прямоугольные оси 0–1 от второго `add_subplot`; мелкие подписи перекрывались. | Убраны лишние оси; мелкие доли объединены в «Прочие»; подписи вынесены в легенду. |
| Bar / Heatmap / Box / Radar / Parallel / Plotly | В легендах и матрицах присутствовали минералы с нулём во всех образцах. | `visible_mineral_fields()` + русские подписи `MINERAL_LABELS`; нулевые строки скрыты. |
| Correlation / Coefficient heatmap | Чёрный текст на тёмно-синих ячейках (и наоборот) в тёмной теме. | Цвет текста выбирается по яркости ячейки. |
| Подписи образцов | Накладывались друг на друга, особенно при 10+ образцах. | `src/charts/labels.py`: перебор offsets, проверка bbox, обрезка имён; при >8 образцах — выносная легенда «цвет → образец» (TAS, QAPF, фельдшпаты, AFM, A-CN-K, Mg-Fe-Al, SiO₂–K₂O, PCA). |

## Визуальные улучшения

- Единая геометрия треугольников и сеток (`src/charts/ternary.py`).
- Общие классификационные поля (`src/charts/classification.py`) — matplotlib и
  Plotly рисуют одни и те же границы.
- Тёмная/светлая тема: подписи, легенды и цвет текста в heatmap учитывают фон.
- Легенды показывают только присутствующие минералы; длинные имена образцов
  сокращаются, лишние подписи отбрасываются.
- Plotly KF синхронизирован с matplotlib (ось F, подсказки с именем образца).
- Correlation исключает постоянные оксиды; Harker не рисует плоский тренд и
  показывает R²; Heatmap скрывает цифры при >400 ячейках; PCA не подписывает
  пренебрежимо малые нагрузки.

## Остаточные точки роста (не в этом аудите)

1. **Точные кривые IUGS/TAS.** Сейчас границы — документированная упрощённая
   схема (прямые/кусочно-линейные). Для публикационной точности нужны
   оцифрованные кривые из первоисточников.
2. **AFM-граница.** Схематичная кривая; для строгой публикации — координаты
   границы Irvine & Baragar из первоисточника.
3. **Подписи выбросов.** Легенда для >8 образцов уже есть; следующий шаг —
   автоматически подписывать только выбросы/крайние точки, чтобы не терять
   контекст внутри плотного облака.
4. **QAPF F-часть.** Реализована QAP-часть (Q ≥ 0); нижний FAP-треугольник
   (фоидные породы) пока не рисуется.
5. **A-CN-K расширенные ориентиры.** Добавлены Pl, Kfs, Ill/Ms, Ka/Gb; можно
   добавить смектит и хлорит, а также стрелку тренда для конкретной выборки.
6. **Plotly-визуальный QA.** Автотесты проверяют HTML/данные, но не рендер;
   для скриншот-тестов нужен headless-браузер (Playwright/CDP).
