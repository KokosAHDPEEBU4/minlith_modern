# Проверка сходимости MINLITH — сверка образцов из файла «Петрохимия скважин 19+свиты»

Файл-источник входных данных: `parity_check/source_petrochemistry.xlsx` (ранее —
`Петрохимия скважин 19+свиты мин состав по группам.xlsx` в корне `Lene/`).
Эталон: **живой оригинальный MINLITH** `src_excel/Ispravlenny_MINLITH1_2010.xlsm`
(win32com, макросы `aut_1` / `aut_1a`).

Архив артефактов сверки — в `parity_check/` (вход, эталон, результаты обоих режимов;
см. `parity_check/README.md`).

## Метод

Для каждого образца каждого листа:
1. входные оксиды читаются из файла;
2. тот же вход прогоняется через **оригинальный Excel MINLITH** (живой COM) и через
   наш движок: `excel_exact` (порт формул+VBA, `rounding=True`) и `excel_parity` (без ROUND);
3. сверяется итоговая строка 287 листа «Нач+Type 12» (массовые %):
   `Ab, An, Pln, Orn, Qn, Mmn, Illn, Chln, Gbn, Knn, Apn, Cn, Ccn, Dln, Ankn,
   Rchn, Sdn, Srpn, Mstn, Htn, Prln, Prn`.

Порог достоверного расхождения: |Δ| > 0.05 (`.md`-колонка «bad»).
Живой Excel-вход пишется в «ИСХ ДАННЫЕ» B2..B19 (18 оксидов); колонки
`BaO/V2O5/Cr2O3/NiO/LOI/ППК` в оригинальном входе отсутствуют и игнорируются.

## Итог

- **`excel_exact` vs оригинал: 85/85 образцов идентичны, max|Δ| = 0.0000, расхождений 0.**
- `excel_parity` vs оригинал: 20 значений > 0.05 на 3 образцах (7913, 7930, 7931) —
  штатный дрейф без пошаговых ROUND (для 1:1 использовать `excel_exact`).

Колонки сверки ниже: `ex_max` / `ex_bad` — excel_exact vs оригинал;
`pa_max` / `pa_bad` — excel_parity vs оригинал.

## Блоки `MINLITH` в самом файле (vs оригинал)

Кроме входных данных, на каждом листе (кроме `88_Letnikova` и `гистограммы`) есть
статический блок `MINLITH` — копия вывода оригинального MINLITH (порядок колонок
`D287..Y287`). Блок посчитан по **одному** образцу листа (не по строке 2). Сверка
«блок ↔ живой оригинал» для этого образца:

| лист | образец блока | maxΔ блок ↔ оригинал |
|------|---------------|----------------------|
| бруская | 7948 (ИМ4-67) | 0.000 |
| бруская-алешинская | 7919 (ИЗ-56) | 0.000 |
| алешинская | 7945 (Ав3-4) | 0.000 |
| оскобинская | 7933 (Тэ1-71) | 0.000 |
| шунтарская | 7942 (Ав3-1) | 0.000 |
| абаканская | 7951 (Ав1-2) | 0.000 |
| чистяковскя | нет совпадения | до 52.3 (блок ошибочный) |

Наш `excel_exact` воспроизводит эти блоки в ноль на 6 листах. Лист `чистяковскя` в файле
содержит некорректные значения (`Illn = −9.49` и др.) и не соответствует ни одному образцу
листа — данные блока считать недостоверными.
