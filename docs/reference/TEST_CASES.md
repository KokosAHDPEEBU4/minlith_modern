## 1. ОБЩИЕ ПРИНЦИПЫ

### 1.1. Источники тестовых данных

| Источник | Описание | Приоритет |
|----------|----------|-----------|
| Оригинальный файл MINLITH1.xlsx | Образцы БК-1, T-O2 | Критический |
| Синтетические данные | Граничные случаи, чистые минералы | Высокий |
| Реальные анализы | Партии образцов из практики | Средний |
| Случайные данные | Fuzzing для стресс-тестов | Низкий |

### 1.2. Критерии прохождения

| Параметр | Допустимое отклонение |
|----------|----------------------|
| Вес.% минералов | ±0.01% от оригинала |
| Формульные единицы | ±0.1 ф.е. от оригинала |
| Сумма вес.% | 99.9% — 100.1% |
| Тип породы | Должен совпадать |

### 1.3. Структура тест-кейса

```
ID: Уникальный идентификатор
Название: Краткое описание
Категория: unit / integration / regression / stress
Приоритет: critical / high / medium / low
Входные данные: Оксиды (вес.%)
Ожидаемый результат: Минералы (вес.%), тип, параметры
Примечания: Особенности, ограничения
```
