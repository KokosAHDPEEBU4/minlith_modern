**Таблица преобразований:**

| Операция | Формула | Размерность | Пример (БК-1) |
|----------|---------|-------------|---------------|
| Вес.% → ф.е. | `fe = wt / M * 10000` | (N, 18) | SiO₂: 52.31/60.084×10000 = 8703.48 |
| Fe₂O₃ → FeO | `feo_total = feo + fe2o3×0.9` | (N,) | 4.43 + 0.92×0.9 = 5.26 вес.% → 732.14 ф.е. |
| Коррекция CaO | `cao -= 3.33 × p2o5_fe` | (N,) | 6.8 - 3.33×1.30 = 2.47 вес.% |
| Коррекция F | `f -= 0.67 × p2o5_fe` | (N,) | 0.41 - 0.67×1.30 = -0.46 |
| Коррекция Na | `na2o -= cl/2` | (N,) | 8.08 - 0 = 8.08 |
| F (окисленность) | `F = fe3/(fe2+fe3)` | (N,) | 0.9194/(4.43+0.9194) = 0.172 |
| A (Al-содержание) | `A = 2×al/(2×al+fe_total)` | (N,) | 2×16.46/(2×16.46+5.26) = 0.862 |
| k1-k4 | По диапазонам F | (N, 4) | F=0.172 → k1=3.53, k2=0.70, k3=1.54, k4=3.23 |

**Ветвление Этапа VI:**

```
Ca_n, Mg_n, Fe_n, Mn_n, Si_n (остатки после Type 1-5)
    │
    ├── Ca_n ≥ Mg_n + Fe_n?
    │   ├── ДА → VI А:
    │   │   Dl = Mg_n
    │   │   Ank = Fe_n
    │   │   Cc = Ca_n - Dl - Ank
    │   │   Rch = Mn_n
    │   │   Q = Si_n
    │   │   Ht = Fe_n/2 (если Ca_n1 ≤ 250)
    │   │   Sd = Fe_n (если Ca_n1 > 250)
    │   │
    │   └── НЕТ → VI Б:
    │       ├── Ca_n < Mg_n?
    │       │   ├── ДА → VI Б:
    │       │   │   Dl = Ca_n
    │       │   │   Mg_n1 = Mg_n - Dl
    │       │   │   Si_n ≥ 2/3 × Mg_n1?
    │       │   │   ├── ДА → Srp = Mg_n1/3, Q = Si_n - 2×Srp
    │       │   │   └── НЕТ → Srp = Si_n/2, Mst = Mg_n1 - 3×Srp
    │       │   │
    │       │   └── НЕТ → VI Б б:
    │       │       (другие ветви...)
    │       │
    │       └── (другие условия...)
    │
    └── Defect = входные_оксиды - оксиды_в_минералах
```
