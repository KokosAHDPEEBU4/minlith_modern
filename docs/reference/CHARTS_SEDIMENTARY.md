# Осадочный набор диаграмм: что удалено и почему

**Актуальный каталог:** `CHARTS_ACTIVE.md` — 8 статических + 6 интерактивных
диаграмм с описанием и скриншотами (`charts_active/`).

Этот файл фиксирует историю сокращения набора: какие диаграммы убраны и по
какой причине. Файлы не уничтожены — перенесены в `_trash/` и могут быть
возвращены, если понадобится отдельный модуль.

## Итог

- было: 23 matplotlib + 14 Plotly = 37;
- стало: 8 matplotlib + 6 Plotly = 14.

## Первая волна: магматические классификации

Удалены как неприменимые к осадочным породам: нормативный расчёт MINLITH
описывает осадочные фазы, а не кристаллизацию расплава.

| Диаграмма | Почему удалена |
|-----------|----------------|
| QAPF (static + Plotly) | классификация плутонических пород по Q–A–P (IUGS/Streckeisen) |
| TAS (static + Plotly) | Total Alkali–Silica для вулканитов |
| Feldspar Triangle | треугольник Ab–An–Or магматических полевых шпатов |
| Harker (static + Plotly) | вариационные диаграммы SiO₂–оксиды для дифференциации |
| AFM (static + Plotly) | треугольник A–F–M для толеитовых/известково-щелочных серий |
| SiO₂–K₂O | диаграмма Peccerillo–Taylor для вулканических серий |
| Mg–Fe–Al Ternary | катионные пропорции мафических/ультраосновных пород |

Каталог `CHARTS_CATALOG.md`, описывавший 37 диаграмм, перенесён в
`_trash/docs/reference/`.

## Вторая волна: дубли и диагностика

Удалены как дублирующие, узкодиагностические или менее полезные в повседневной
работе. Основные сценарии закрывают bar, pie, defect, A-CN-K, heatmap,
rock type, box plot и PCA.

| Диаграмма | Почему удалена |
|-----------|----------------|
| Bland–Altman | нужна только для сверки движков, не для анализа пород |
| Correlation | контроль аналитики дублируется heatmap/предупреждениями |
| Коэффициенты хлорита vs F | внутренняя диагностика алгоритма, не свойство породы |
| Radar | дублирует pie/bar для одного образца |
| Coefficient Heatmap | дублирует KF-диаграмму и таблицу коэффициентов |
| Defect Accumulation | дублирует Defect Chart |
| Dendrogram | перекрывается PCA-биплотом |
| Parallel Coordinates | перекрывается PCA и heatmap |
| Plotly `correlation` | дубль удалённой статической корреляции |
| Plotly `kf` | дубль удалённой KF-диаграммы |
| Plotly `violin` | дублирует box plot для основного сценария |
| Plotly `parallel` | дубль удалённых параллельных координат |

## Что осталось и почему

| Диаграмма | Роль |
|-----------|------|
| Mineral Bar / Pie | состав: сравнение проб и один образец |
| Defect | контроль невязки и качества входа |
| A-CN-K | выветривание и глинистые минералы — единственная классическая схема для осадочных пород |
| Mineral Heatmap | структура выборки |
| Rock Type Distribution | представительность типов 1–5 |
| Mineral Box Plot | разброс и выбросы |
| PCA Biplot | группировка и главные тренды |
| Plotly bar/pie/acnk/heatmap/boxplot/rock_type | интерактивные версии основных видов |

Подробное описание каждой оставшейся диаграммы — в `CHARTS_ACTIVE.md`.
