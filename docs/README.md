## Как добавить документ

1. Класть в правильный раздел (`algorithm/`, `reference/`, `planning/`).
2. Добавить строку в таблицу этого файла и, при необходимости, в корневой `README.md`.
3. Ссылки из других документов держать относительными (`../reference/…`).
