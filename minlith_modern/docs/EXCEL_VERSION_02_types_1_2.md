# EXCEL_VERSION_02 — Типы 1 и 2 (лист «Нач+Type 12», строки 44-283)

**Лист:** `Нач+Type 12`
**Диапазоны:** тип 1 — строки 44-90; тип 2 — строки 172-283
**Сверка:** Python-VM совпадает с Excel для БК-1 и аркозового образца (тип 1),
гранитного (тип 2) — включая отрицательные промежуточные значения.

> Все количества в формульных единицах (ф.е., см. `EXCEL_VERSION_01`).
> Обозначения: `na`=Na₂O·ф.е., `k`=K₂O·ф.е., `ca`=CaO·ф.е., `mg`=MgO·ф.е.,
> `Si`=D2 (SiO₂·ф.е.), `Al`=D4 (Al₂O₃·ф.е.), `fe1`=Fe₁ = I21 = D6 − pyrite.
> Строки выводят остатки оксидов `ca_n, mg_n, fe_n, si_n` (B93-B95, F93),
> которые затем распределяются стадией VI (`EXCEL_VERSION_04`).

---

## 1. Общая подготовка (строки 45-46)

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| B45 | `=1*D9` | **ab = na** (альбит берёт весь Na) |
| E45 | `=D2-B45*6` | Si после альбита: `Si − 6·na` |
| B46 | `=1*D10` | **or = k** (ортоклаз берёт весь K) |
| E46 | `=E45-6*B46` | Si после альбита+ортоклаза: `Si − 6·na − 6·k` |
| E47 | `=D4-B46-D10` | Al для анортита: **`Al − 2·k`** *(в оригинале K вычитается дважды — особенность книгu, сохраняется)* |
| G45 | `=D2` | Si исходный (вспомогательный) |

Полевые шпаты «забирают» O⁻: альбит NaAlSi₃O₈ — 1 Al и 6 O на Na,
ортоклаз KAlSi₃O₈ — то же на K. Остатки `E46` (Si) и `E47` (Al) управляют
выбором ветки анортита.

---

## 2. Выбор ветки анортита (флаги, строки 49-83)

Столбец C — «кандидаты», столбец D — булев флаг `IF(TRUE, C...)`.

| Флаг | Кандидат C | Условие (флаг=ИСТИНА) |
|------|------------|------------------------|
| D49 | `E47 − ca` | Al для An ≤ Ca (Ca избыточен) |
| D51 | `E46 − 2·E47` | Si не лимитирует An из всего Al |
| D52 | `E47` | Al остаток > 0 |
| D58 | `E46 − 2·E47` | Si не хватает на An из Al (D51 противоположен) |
| D67 | `E46 − 2·ca` | Si хватает на An из всего Ca |
| D73 | `(E47−ca) − (E46−2·ca)` | Al остаток ≥ Si остаток |
| D78 | `(E47−ca) − (E46−2·ca)` | Al остаток < Si остаток |
| D83 | `E46 − 2·ca` | Si не хватает на An из Ca (D67 противоположен) |

Анортит CaAl₂Si₂O₈ «забирает» 1 Ca + 1 Al + 2 Si на формульную единицу
по каждому катиону ф.е. (поэтому в формулах `2·An` по Si).

### 2.1. Проверенная ветка «Si не хватает» (строки 83-87) — БК-1

Условия БК-1: `D49=ЛОЖЬ`, `D67=ЛОЖЬ` (Si<2·ca). Результат:

| Ячейка | Формула | Значение (БК-1) |
|--------|---------|-----------------|
| C84 | `=E46/2` | **an = Si₂/2** = −914.99 |
| C86 | `=E47-C84` | Al остаток после An: `Al₁ − Si₂/2` |
| C87 | `=ca-C84` | **ca_n = ca − Si₂/2** = 1585.99 |
| B93 | `=C87` | ca_n |
| F93 | `=0` | si_n = 0 (весь Si ушёл) |
| G147 | `=C84` | an |

### 2.2. Проверенная ветка «Al < 0, An из бюджета Na» (строки I52-I54) — аркоз

Условия аркоза (t1): `D49=ИСТИНА`, `D51=ИСТИНА`, `D52=ЛОЖЬ` (Al₁≤0).

| Ячейка | Формула | Значение (аркоз) |
|--------|---------|------------------|
| I52 | `=0.2*na` | **an = 0.2·na** = 96.80 |
| I53 | `=ca-I52` | **ca_n = ca − 0.2·na** = −8.80 |
| I54 | `=E46-2*I52` | **si_n = Si₂ − 2·(0.2·na)** = 4729.70 |
| B93 / P147 | `=I53` | ca_n |
| F93 / M147 | `=I54` | si_n |

### 2.3. Остальные ветки (строки 49-83)

Формулы приведены в таблице флагов выше; точное сочетание «C-ячейки →
именованные ячейки» задаёт VBA (`t_49`, `t_51`, `t_52an`, `t_53an`).
Общий смысл трёх семейств:
- **Al-лимит** (`D49=ИСТИНА`): `an = Al₁`, `ca_n = ca − Al₁`, `si_n = E46−2·Al₁` (C53-C54);
- **Ca-лимит / Si-дефицит** (`D67=ИСТИНА` при `D49=ЛОЖЬ`): `an = ca`, `si_n = E46−2·ca` и остатки Al (C68-C71, C73-C80);
- **Дефицит Si** (`D83=ИСТИНА`): ветка 2.1 (C84-C87).

Остатки `mg_n` и `fe_n` для типа 1 простые:
- `B94` = mg_n = `D7` (весь Mg),
- `B95` = fe_n = `I21` = `D6 − H20` (Fe минус пирит, `pr0 = s/2`, C21); для B95/2 см. стадию VI.

## 3. Тип 2 (граниты, строки 172-283)

Классификация (лист «Нач+Type 3»): `Type 2` при `Al ≤ 1.2·Na + 3.25·K`
(флаг `F22`, строка 22: `E22 = Al − (1.2·na + 3.25·k)`; `F22 = E22 ≤ 0`).

### 3.1. Плагиоклаз (строки 174-196) — проверено на граните

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C174 | `=D9*1` | **ab = na** |
| C175 | `=D2-6*C174` | Si после Ab: `Si − 6·na` |
| C177 | `=C175-6*k-0.4*na` | Si после Ab + Or + 0.4·na (An-бюджет) |
| D177 | `=IF(TRUE,C177<0)` | флаг Si-дефицита |
| C192 | `=ca-0.2*na` | Ca после An = 0.2·na |
| D192 | `=IF(TRUE,C192>=0)` | если Ca достаточно → ветка a |
| C193 | `=0.2*na` | **an = 0.2·na** |
| C194 | `=C175-2*C193` | Si после An: `Si − 0.4·na` |
| C195 | `=D4-C174-C193` | **al_1 = Al − na − 0.2·na** (Al после Ab+An) → I173 |
| C196 | `=ca-C193` | Ca остаток после An |
| I176 | `=C194` | **si_2** (Si после Ab+An) |

Проверено (гранит): `ab=564.68`, `an=112.94`, `al_1=695.38`, `si_2=8368.05`.

### 3.2. Иллит и ортоклаз с учётом Si (строки 204-218) — проверено

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C204 | `=si_2-(11.5*k+2*al_1)/2.25` | Si запас для иллита+ортоклаза |
| D204 | `=IF(TRUE,C204>=0)` | флаг достаточности Si |
| C208 | `=0.2*na-ca-(3.25*k)` | Ca дефицит при заметном K |
| D208 | `=IF(TRUE,C208<0)` | флаг |

Если оба флага ИСТИНА (гранит): иллит, ортоклаз и хлорит.

| Ячейка | Формула | Значение (гранит) |
|--------|---------|-------------------|
| C214 | `=ROUND((al_1-k)/4.5,1)` | **ill = (al_1 − k)/4.5** = 48.4 |
| C215 | `=ROUND(k-2*C214,1)` | **or = k − 2·ill** = 380.9 |
| C216 | `=fe3_1-C214` | Fe после иллита |
| C217 | `=mg-C214` | Mg после иллита |
| C218 | `=si_2-16*C214-6*C215` | **si_n = si_2 − 16·ill − 6·or** = 5308.25 |

Коэффициенты стехиометрии: иллит KAl₂(Si₃Al)O₁₀(OH)₂·nH₂O — 2 K на 6.5 Al
и 16 Si на 6 K... — в расчётной форме 1 ill к 6.5 Al, 16 O, 2 K; ортоклаз
1 K к 6 O. `fe3_1 = I21 = fe1` (Fe после пирита).

### 3.3. Ветки дефицита Si (C204<0, C208≥0)

При недостатке Si ветвь строк 213-218 меняется: ортоклаз ограничен
свободным Si (`or = (si_2 − 16·ill)/6`), остальное как в 3.2. Точные
формулы — в строках 204-218 на листе; эталон гранита идёт по ветке 3.2.

Остатки для стадии VI (гранит, проверено):
`ca_n = B93 = 107.06`, `mg_n = B94 = 75.6`, `fe_n = B95 = 241.12`,
`si_n = F93 = 5308.25`.

## 4. Итоги типа (что попадает в выводимые минералы)

Для обоих типов VBA копирует результаты в строку 147; оконч. минералы
см. `EXCEL_VERSION_05`. Ключевые соответствия:

| Минерал | Ячейка 147 | Тип 1 (аркоз/БК-1) | Тип 2 (гранит) |
|---------|-----------|--------------------|----------------|
| ab | F | = na | = na |
| an | G | по ветке §2 | = 0.2·na |
| ill | I | 0 | = (al_1−k)/4.5 |
| or | J | = k | = k − 2·ill |
| q | M | = si_n | = si_n |
| dl | P | = ca_n (или 0, см. VI) | = mg_n (стадия VI) |
| ank | K | — | = ca_n − mg_n |
| ht | U | = fe_n/2 | = fe_n/2 |
| prl | S | = Mn | = Mn |

Стадия VI (строки 92-140) дораспределяет Ca/Mg/Fe/Mn — см. `EXCEL_VERSION_04`.
