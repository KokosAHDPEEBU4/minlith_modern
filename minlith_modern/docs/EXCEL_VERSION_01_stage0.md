# EXCEL_VERSION_01 — Стадия 0 (подготовка)

**Лист:** `Нач+Type 3` (коэффициенты и классификация) и `Нач+Type 12`
**Источник:** `Ispravlenny_MINLITH1_2010.xlsm`
**Сверка:** Python-реплика совпадает с Excel (COM) для БК-1 и T-O2.

---

## 1. Что делает стадия 0

1. Переводит вес.% оксидов в **формульные единицы (ф.е.)** — колонка D.
2. Считает `F = Fe³⁺/ΣFe` и `A = Al/(Al+Fe)` — ячейки G2, I2.
3. **Выбирает** коэффициенты хлорита k1-k4 и формульный вес `achl` из
   таблицы-кандидата по диапазону F (в оригинале — макросы `u_0..u_10`).
4. **Классифицирует** тип породы (1-5) по флагам F20-F26.

Вход — колонка **B** (вес.%), молярные массы — колонка **C**.

---

## 2. Перевод в формульные единицы (колонка D)

Формула в общем виде: `ф.е. = вес.% / M * 10000`, с округлением.

| Ячейка | Оксид | Формула Excel | Примечание |
|--------|-------|---------------|------------|
| D2 | SiO₂ | `=ROUND(B2*10000/C2,0)` | до целых |
| D3 | TiO₂ | `=B3` | **без пересчёта** (значение как есть) |
| D4 | Al₂O₃ | `=ROUND(B4*10000/C4,0)` | до целых |
| D6 | FeO общ. | `=ROUND((B5*0.9+B6)*10000/C6,0)` | Fe₂O₃·0.9 + FeO |
| D7 | MgO | `=ROUND(B7*10000/C7,0)` | |
| D8 | CaO | `=ROUND(B8*10000/C8,0)-ROUND(3.33*B11/C11*10000+B15/C15*10000/2,0)` | − апатит (3.33·P₂O₅) − F/2 |
| D9 | Na₂O | `=ROUND(B9*10000/C9,2)-ROUND(B16/C16/2*10000,2)` | − галит (Cl/2) |
| D10 | K₂O | `=ROUND(B10*10000/C10,2)` | |
| D11 | P₂O₅ | `=ROUND(B11*10000/C11,2)` | |
| D12 | MnO | `=ROUND(B12*10000/C12,2)` | |
| D13 | C | `=B13` | **без пересчёта** |
| D14 | SO₃ | `=ROUND(B14/C14*10000,2)` | |
| D15 | F | *(текст-заглушка)* | **не вычисляется, нигде не используется** |
| D16 | Cl | `=ROUND(B16/C16*10000,2)` | |
| D17 | S | `=ROUND(B17/C17*10000+D14,2)` | S ф.е. + SO₃ ф.е. |
| D18 | CO₂ | `=ROUND(B18/C18*10000,2)` | |
| D19 | SO | `=ROUND(B19/C19*10000,0)` | |

**Важно:**
- `D15` (F) в оригинале — **текстовая строка** `'ROUND(B15/C15*10000;2)-0,67*D11'`
  (с русским разделителем `;`), т.е. НЕ формула. Ссылок на D15 нет — на результат
  не влияет. При порте F ф.е. = 0.
- FeO общ. = Fe₂O₃·0.9 + FeO (коэффициент **0.9**, не 1.0).
- CaO корректируется на апатит **3.33·P₂O₅** и флюорит **F/2**.
- Na₂O корректируется на галит **Cl/2**.

## 3. Параметры F и A

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| G2 | `=ROUND(D6/(D6+D7),3)` | `F = FeO_общ / (FeO_общ + MgO)` |
| I2 | `=ROUND(2*D4/(2*D4+D6+D7),3)` | `A = 2·Al₂O₃ / (2·Al₂O₃ + FeO_общ + MgO)` |

Оба округляются до **3 знаков**.

## 5. Выбор коэффициентов (макросы `u_0..u_10`)

Флаги диапазонов (лист `Нач+Type 3`):

| Ячейка | Формула | Диапазон |
|--------|---------|----------|
| G17 | `=AND(TRUE,G2>0,G2<0.21)` | 1 (H5:H9) |
| H17 | `=AND(TRUE,G2>=0.21,G2<0.51)` | 2 (J5:J9) |
| I17 | `=AND(TRUE,G2>=0.51,G2<0.69)` | 3 (L5:L9) |
| J17 | `=AND(TRUE,G2>=0.69,G2<0.87,I2>0.47)` | 4 (H12:H16) |
| G18 | `=AND(TRUE,G2>0.69,G2<0.87,I2>0.4,I2<0.47)` | 5 (J12:J16) |
| I18 | `=AND(TRUE,G2>=0.87,G2<1)` | 6 (L12:L16) |

Каскад VBA (`u0 → u_2 → u_4 → u_6 → u_8`):

```
u0: если G17 -> u_1 (копирует H5:H9 в k_1)  иначе u_2
u_2: если H17 -> u_3 (J5:J9)  иначе u_4
u_4: если I17 -> u_5 (L5:L9)  иначе u_6
u_6: если J17 -> u_7 (H12:H16)  иначе u_8
u_8: если G18 -> u_9 (J12:J16)  иначе u_10 (L12:L16)
```

Каждый `u_N` копирует 5 ячеек (k1,k2,k3,k4,achl) в **F12:F16**
(именованные диапазоны `k_1`=F12, `k_2`=F13, `k_3`=F14, `k_4`=F15,
`achl`=F16). Затем копирует блок `A1:F19` из Type 3 в Type 12.

## 6. Классификация типа породы (флаги F20-F26)

| Ячейка | Формула | Условие | Тип |
|--------|---------|---------|-----|
| E20 | `=D4-D9-D10` | | |
| F20 | `=IF(TRUE,E20<0)` | Al < Na+K | 1 |
| E21 | `=D4-(1.2*D9+D10)` | | |
| F21 | `=IF(TRUE,E21<=0)` | Al ≤ 1.2Na+K | 1 |
| E22 | `=D4-(1.2*D9+3.25*D10)` | | |
| F22 | `=IF(TRUE,E22<=0)` | Al ≤ 1.2Na+3.25K | 2 |
| E24 | `=ROUND(D4-(1.2*na+3.25*k+(mg-0.5*k)*k_3/k_1),2)` | | |
| F24 | `=IF(TRUE,E24<=0)` | Al ≤ 1.2Na+3.25K+(Mg−0.5K)·k3/k1 | 3 |
| E25 | `=ROUND(D4-(5*na+3.25*k+(mg-0.5*k-2*na)*k_3/k_1),2)` | | |
| F25 | `=IF(TRUE,E25<=0)` | Al ≤ 5Na+3.25K+(Mg−0.5K−2Na)·k3/k1 | 4 |
| E26 | `=ROUND(D4-((5*D9+3.25*D10)+(D7-0.5*D10-2*D9)*F14/F12),2)` | | |
| F26 | `=IF(TRUE,E26>0)` | иначе | 5 |

Здесь `na`, `k`, `mg`, `k_1..k_4` — именованные диапазоны (D9, D10, D7, F12-F15).

Порядок проверки (VBA `v_1..v_14`):
```
F20 -> aType_1
иначе F21 -> aType_1
иначе F22 -> aType_2
иначе F24 -> aType_3
иначе F25 -> aType_4
иначе      aType_5
```

**Примечание:** E24/E25 зависят от выбранных k1, k3 — поэтому классификация
типа возможна только ПОСЛЕ выбора коэффициентов.

## 8. Открытые вопросы

1. **D15 (F ф.е.)** — мёртвая текстовая ячейка; подтверждено, что ни одна
   формула на неё не ссылается. При порте = 0.
2. **H12 = 0.56** — константа (не формула). Возможно, эмпирическая правка
   автора; воспроизводим как есть.
3. **J12 = 6.2−12·A** — использует A (I2), тогда как «симметричная» формула
   для k1 в диапазоне 4 по TZ — `6.2−12·F`. Воспроизводим как в оригинале;
   это может быть особенностью (или ошибкой) автора.
