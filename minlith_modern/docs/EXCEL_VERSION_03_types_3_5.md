# EXCEL_VERSION_03 — Типы 3, 4 и 5 (лист «Нач+Type 3», строки 44-556)

**Лист:** `Нач+Type 3`
**Диапазоны:** тип 3 — строки 44-142 (переменные `al3_*/si3_*/fe3_2/ill_3`);
типы 4-5 — строки 268-556 (переменные `al4_*/si4_*/mg4_1/fe4_2/...`).
**Сверка:** Python-VM совпадает с Excel для T-O2 и базальта (тип 3),
кварцита (тип 4) и высокоглинозёмистого образца (тип 5).

> Обозначения как в `EXCEL_VERSION_02`. Данные типы считаются целиком на
> листе «Нач+Type 3»; VBA лишь копирует выбранные коэффициенты в именованные
> ячейки (`I47..I57`, `H271..H286` и т.д.) и переносит блоки на «Нач+Type 12»
> для стадии VI и вывода.

---

## 1. Тип 3 (базальты, строки 44-142)

Классификация (строки 22-24): `Type 3` при
`Al ≤ 1.2·na + 3.25·k + (mg − 0.5·k·k_3)/k_1`.

### 1.1. Плагиоклаз (строки 46-72)

Общая часть:

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C46 | `=na` | ab |
| C47 | `=D2-6*C46` | si3_1 = Si − 6·na |
| C48 | `=D4-C46` | al3_1 = Al − na |
| C50 | `=ca-0.2*na` | Ca после 0.2·na |
| C51 | `=C47-6*k-0.4*na` | Si после Ab+Or+0.4·na |
| D51 | `=AND(C50>=0,C51<0)` | флаг 1 (Ca есть, Si нет) |
| C52 | `=ca-0.2*na` | |
| C53 | `=C47-6*k-2*ca` | Si− 6k − 2ca |
| D53 | `=AND(C52<0,C53<0)` | флаг 2 (Ca и Si не хватает) |
| C54 | `=k*1` | |
| C55 | `=(si3_1-6*C54)/2` | |
| C57 | `=ca-C55` | Ca остаток |
| C58 | `=al3_1-k-C55` | Al остаток |
| C61 | `=si3_1-6*k-0.4*na` | Si запас для An=0.2na |
| D61 | `=AND(C60>=0,C61>=0)` | флаг 3 (Ca и Si хватает) |

При `D61=ИСТИНА` (основная проверенная ветка, базальт/T-O2):

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C62 | `=ROUND(0.2*na,2)` | **an = 0.2·na** |
| C63 | `=si3_1-2*C62` | si3_2 = Si после An |
| C64 | `=al3_1-C62` | al3_2 = Al после An |
| C65 | `=ca-C62` | ca_n = Ca после An |

### 1.2. Иллит (строки 74-123)

Иллит `KAl₂...` берёт 1 K, 6.5 Al, 16 Si; хлорит `(Mg,Fe,Al)₆...` —
коэффициенты `k_1..k_4` (Mg/Fe/Al/Si), см. `EXCEL_VERSION_01`.

Проверенная ветка (базальт, строки 116-123):

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C116 | `=0.5*D10` | **ill_3 = 0.5·k** (K-лимит: иллит берёт K/2, вторая K на ортоклаз) |
| C120 | `=(al3_2-6.5*ill_3)/F14` | хлорит-кандидат по Al: `chl = (al3_2−6.5·ill)/k_3` |
| C121 | `=mg-ill_3-C120*k_1` | **mg_n = mg − ill − chl·k_1** (остаток Mg) |
| C122 | `=fe3_1-ill_3-k_2*C120` | **fe_n = fe1 − ill − chl·k_2** |
| C123 | `=si3_2-16*ill_3-k_4*C120` | **si_n = si3_2 − 16·ill − chl·k_4** |
| I57 | `=C116` | ill_3 |
| I55 | `=C122` | fe3_2 |
| I52 | `=C123` | si3_3 |

Проверено (базальт): `ill=26.54`, `chl=625.90`, `mg_n=333.24`,
`fe_n=178.86`, `si_n=3596.25`. Важно: **хлорит берётся по Al** (k_3)
при K-ограниченном иллите.

### 1.3. Остальные ветки иллита/хлорита (строки 74-142)

Доступны флаги, разбирающие случаи дефицита разных компонентов:

- строки 90-102: хлорит по Mg (флаг `D90`: `4.5·mg − al3_2 + k ≥ 0`);
- строка 102: `C102 = ROUND(F14*(4.5*mg-C64+k)/(4.5*F12-F14),0)` — альтернативный хлорит;
- строки 105-112, 132-139: проверка остатков Fe/Si (`fe3_2`, `si3_3`) после хлорита;
- строки 114-123: K-ограниченный иллит (проверенная ветка);
- строки 126-130: иллит по Mg (`C127=(mg−C116)/F12`).

Общий порядок в ветках 3: **ab → an → or → ill → chl → остатки**.
Хлорит выбирается тем компонентом, который «кончается» первым
(лимитирующим), остальные соотношения доводятся коэффициентами k1-k4.

## 2. Типы 4 и 5 (строки 268-556)

Классификация: `Type 4` при
`Al ≤ 5·na+3.25·k+(mg−0.5·k−2·na)·k_3/k_1`; иначе `Type 5`.
Особенности: монтмориллонит (`mm`), гиббсит (`gb`) у типа 5, анортит с
Ca-бюджетом 0.2, хлорит и иллит с теми же коэффициентами k1-k4.

### 2.1. Общие формулы (строки 271-292)

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C275 | `=k` | ab-кандидат |
| C276 | `=D2-6*C275` | si4_1 = Si − 6k |
| C277 | `=D4-C275` | al4_1 = Al − k |
| C279 | `=al4_1-5*na` | Al после 5·na (5 Al на na → монтмориллонит/спуд) |
| D279 | `=IF(C279<=0)` | флаг Al-дефицита |
| C281 | `=mg0-(al4_1-1.2*na)/1.9` | Mg-бюджет |
| C282 | `=(al4_1-1.2*na)/3.8` | кандидат |
| C283 | `=mg0-2*C282` | |
| C284 | `=al4_1-5*C282` | |
| C285 | `=si4_1-24*C282` | |
| C287 | `=C285-6.4*(na-mm_4)` | флаг Si для mm |
| C288 | `=na-mm_4` | |
| C289 | `=C285-6*C288` | |
| C290 | `=0.2*C288` | an-бюджет от (na−mm) |
| C291 | `=C289-2*C290` | si_n после An |
| C292 | `=ca-C290` | ca_n |
| C294 | `=C292*1`; `D294=IF(C294>0)` | флаг ca_n>0 |

Проверено (T-O2/кварцит) основное соотношение:
`mm_4` (монтмориллонит) находится первым; `an_4 = 0.2·(na−mm)`;
`ca_n = ca − an_4`; `si_n = si − … − 2·an_4`.

### 2.2. Хлорит/Fe-фазы (строки 385-442)

| Ячейка | Формула | Смысл |
|--------|---------|-------|
| C385 | `=fe3_1-k/2` | флаг Fe против K/2 |
| D385 | `=IF(C385<=0)` | |
| C386 | `=fe3_1` | кандидат хлорита по Fe |
| C402 | `=k/2` | ill = K/2 |
| C403 | `=D2-16*C402` | Si после ill |
| C404 | `=D4-6.5*C402` | Al после ill |
| C405 | `=fe3_1-C402` | Fe после ill |
| C406 | `=mg0-C402` | Mg после ill |
| C414 | `=1.9*k_1-k_3` | флаг коэффициентов |
| C435 | `=(1.9*mg4_1+1.2*na-al4_1)/(1.9*k_1-k_3)` | хлорит-кандидат по Mg/Al |
| C437 | `=chl_4-al4_1/k_3` | хлорит vs Al-бюджет |
| C438 | `=(mg4_1-k_1*chl_4)/2` | mst-бюджет |
| C439 | `=na-C438` | |
| C440 | `=0.2*C439` | an-бюджет |
| C441 | `=fe4_2-k_2*chl_4` | fe_n после хлорита |
| C442 | `=si4_1-k_4*chl_4-24*C438-6*C439-2*C440` | si_n |

### 2.3. Остальные ветки типов 4-5 (строки 296-556)

Структура повторяет принцип «лимитирующего компонента»:
- строки 296-343: Mg-дефицит (`mx`-ветка: `mg0` против `2·na`, an через `0.2·...`);
- строки 346-364: Si-дефицит при 6·na (монтмориллонит без хлорита);
- строки 371-383: ещё одна ветка анортита/hügel;
- строки 385-448: хлорит/иллит/субго (проверено на кварците);
- строки 450-484: ветка с хлоритом по Mg и Ca-анортитой;
- строки 486-520: хлорит по Fe (`fe4_2/k_2`, C486), an по Si;
- строки 528-556: иллит K/2 с проверками Fe/Mg/Si (тип 5, high-al).

Полный список формул веток — в строках 268-556 листа; ниже приведены
наблюдаемые итоговые значения переменных для эталонов.
