## 2. Строки 149-153 — вес.% и двойная нормировка

**Шаг 1 (149):** вес.% = ф.е. × молярная_масса / 10000 (без округления,
кроме `S149 = ROUND(S147*B41/10000,2)` для prl):

| Минерал | Формула 149 |
|---------|-------------|
| ab | `ab*B31/10000` |
| an | `G147*B32/10000` |
| chl | `H147*achl/10000` |
| ill | `I147*B38/10000` |
| or | `J147*D34/10000` |
| ank | `K147*B34/10000` |
| cc | `L147*B35/10000` |
| q | `q*D36/10000` |
| dl | `P147*B36/10000` |
| rch | `Q147*D37/10000` |
| sd | `R147*B39/10000` |
| prl | `ROUND(S147*B41/10000,2)` |
| srp | `T147*B40/10000` |
| ht | `U147*D38/10000` |
| mst | `V147*D33/10000` |
| gb | `W147*B37/10000` |
| kn | `kn*D31/10000` |
| mm | `Y147*D32/10000` |
| (S) | `pr0*D35/10000` — пирит |
| Cl | `cl/2*D41/10000` (AA149) |
| SO | `so*D40/10000` (AC149) |
| TiO₂ | `B3*1` (N149) |
| C | `c0` (Z149) |
| P₂O₅ | `D11*B33/10000` (E149, апатит) |

**Шаг 2 (150):** нормировка к 100: `ROUND(149*100/$D$151, n)`, где
`D151 = SUM(E149:AC149)` — сумма сырых вес.%. Точность `n` по минералам:
Ab/An/Or/Q 3-2, большие (Chl/Ill/Srp/Ht) 4, карбонаты 2.

**Шаг 3 (153):** повторная нормировка к 100: `ROUND(150*100/$D$152, n)`,
где `D152 = ROUND(SUM(E150:AC150),4)`. Точность: An 3, остальные 4.

Итого тройное округление (149→150→153) воспроизводит итог образца
до 2 знаков в строке 287.

## 5. Дефект (строки 163-171) — невязка оксидов

```
D163 = B1                                  (служебный счётчик)
D164 = ROUND(D2 − Σ(SiO₂), 2)              невязка кремнезёма
D165 = ROUND(D4 − Σ(Al₂O₃), 2)             алюминия
D166 = ROUND(na − Σ(Na₂O), 2)              натрия
D167 = ROUND(k − Σ(K₂O), 2)                калия
D168 = ROUND(mg − Σ(MgO), 2)               магния
D169 = ROUND(D6 − Σ(FeO), 2)               железа
D170 = E6 − Σ(CaO)                          кальция (*без* ROUND, E6 = сырой CaO ф.е.)
D171 = D12 − Σ(MnO)                         марганца
```

Невязка показывает, сколько оксида осталось после учёта всех минералов;
≈0 означает, что баланс сходится. Проверено: для эталонов |D164..D171| ≤ 0.7,
исключение — высокоглинозёмистый образец (алюминиевый дефект частично
уходит в mm/kn/gb). Значения строк 164-171 записываются VBA на лист
`defect` (строки оригинала 164-171 ↔ вывод 2-...).
