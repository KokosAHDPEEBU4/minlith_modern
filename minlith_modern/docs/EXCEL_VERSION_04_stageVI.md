# EXCEL_VERSION_04 — Стадия VI (распределение Ca/Mg/Fe/Mn) — строки 92-140

**Лист:** `Нач+Type 12`, строки 92-140
**Вход:** остатки ф.е. после стадии типа: `ca_n = B93`, `mg_n = B94`,
`fe_n = B95`, `si_n = F93` (строки 93-95).
**Выход:** доломит/анкерит/кальцит/магнезит/серпентин/гематит/пиролюзит
(строки K-P, S-U строки 147 и 285-287).
**Сверка:** три ветки проверены на образцах аркоза (T1), гранита (T2),
базальта (T3); кварцит (T4) и high-al (T5) дают вспомогательные ветки.

> Смысл: остаточные элементы Ca, Mg, Fe, Mn распределяются по
> карбонатным и оксидным фазам. Выбор ветки — по соотношению остатков
> (`D97`, `D105`, `D121`).

## 2. Проверенные ветки

### 2.1. Ветка A «много Ca» (D97=ИСТИНА) — базальт (T3)

```
dl  = mg_n                       (333.24)
ank = ROUND(fe_n, 0)             (179.00)   ← весь Fe уходит в анкерит!
cc  = ca_n − mg_n − ROUND(fe_n,0)(1209.09)
prl = Mn                          (2.45)
q   = si_n                        (3596.25)
```

### 2.2. Ветка B «Ca между Mg и Mg+Fe» (D105=ИСТИНА) — гранит (T2)

```
dl  = mg_n                       (75.60)
ank = ca_n − mg_n                (31.46)
ht  = (fe_n − ank)/2  при (ca_n−mg_n) ≤ 250   (104.83)
prl = Mn                          (2.45)
q   = si_n                        (5308.25)
```

Если `(ca_n − mg_n) > 250` (`D116=ИСТИНА`), то `ht = fe_n − ank` (без деления)
и строки C117-C119.

### 2.3. Ветка C «мало Ca» (D121=ИСТИНА) — аркоз (T1)

```
dl  = ca_n                       (−8.80, отрицательный остаётся отрицательным)
Сф  = mg_n − ca_n                 (82.80)   Mg на серпентин
srp = Сф/3   при si_n достаточен  (27.60)
ht  = fe_n/2                      (78.76)
prl = Mn                          (2.45)
q   = si_n − 2·srp                (4674.49)
```

Если Si не хватает (`D131`), серпентин ограничен Si: `q = si_n/2`,
`srp = Сф − 3·q`. Если `si_n = 0` (`D137`): `srp = Сф`, `ht = fe_n`.

---

## 3. Примечания

- **Отрицательные значения не обрезаются** вплоть до стадии VI
  (например, `dl = ca_n = −8.8` у аркоза); обрезка происходит только в
  выводе (`EXCEL_VERSION_05`).
- Коэффициенты стехиометрии: серпентин Mg₃Si₂=3 Mg, 2 Si (поэтому
  `srp = Сф/3`, `Si − 2·srp`); гематит Fe₂O₃ = 2 Fe (поэтому `ht = fe/2`).
- Порог **250 ф.е.** (строки C111/C116) — произвольная константа
  оригинальной книги; разделяет режимы анкерит-«много» и анкерит-«мало».
- Ветки для остальных сочетаний флагов (D105/D111/D116/D125/D131/D137)
  покрываются формулами раздела 1; эталоны типов 4-5 дают доп. ветки
  строк 285-287 (заполнение `sd`, `mst`, `rch`, `mm`).
