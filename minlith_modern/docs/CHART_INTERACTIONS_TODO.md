## 6. Пакетный пересчёт (Bulk Re-calculation)

- **Что:** Автоматический пересчёт всех загруженных образцов при смене метода
  расчёта в «Настройках».
- **Почему:** Сейчас после смены алгоритма нужно вручную перезагружать файлы.
- **Объём:** Средний. Нужно: чекбокс в «Настройках» (авто-батч), сигнал в
  `MainWindow` на смену настроек, вызов `calculate_batch` при включённом чекбоксе.
- **Точки входа:** `SettingsPage`, `MainWindow`, `CalculationWorker`.

## 1. Drill-down по срезу pie (клик → детализация)

- **Что:** по клику на сектор круговой диаграммы показывать детализацию (например,
  список образцов/значений, попавших в категорию).
- **Почему отложено:** нужна модель данных второго уровня, которой нет в `ChartData`
  (`src/charts/base.py`) — сейчас хранятся только агрегаты по категориям.
- **Объём:** архитектурный. Требуется: расширить `ChartData` (связь «категория →
  образцы/значения»), прокинуть из `build_data_from_results()`
  (`src/gui/pages/charts_page.py`), добавить UI детализации (диалог/панель) и
  обработку клика в `_ChartTile._on_click` (`chart_grid.py`).
- **Точки входа:** `_ChartTile._on_click`, `_connect_pie_events`, `ChartData`,
  `ChartsPage.build_data_from_results`.

## 2. Resize плитки колесом для pie

- **Что:** колесо над круговой диаграммой меняет размер плитки в сетке (не зум
  самой диаграммы).
- **Почему отложено:** ценность спорная; риск конфликта с прокруткой сетки.
- **Объём:** средний. Нужны: изменение `QGridLayout`-span/`setFixedSize` плитки,
  обработка колеса на уровне плитки (сейчас колесо уходит в зум/пан), пересчёт
  layout сетки, сохранение поведения при `_reflow_tiles`.
- **Точки входа:** `_ChartTile._on_scroll`, `_ChartTile.set_figure`,
  `MultiChartView._reflow_tiles`.

## 3. Подпись текущего классификационного поля при зуме (TAS/QAPF)

- **Что:** при приближении TAS/QAPF-диаграммы подписывать, в какое
  классификационное поле попадает текущий вид (обратное преобразование координат).
- **Почему отложено:** требует обратного преобразования координат — отдельная
  задача к рендерерам, а не к слою взаимодействия.
- **Объём:** крупный. Нужны: обратное отображение (x, y) → поле в рендерерах
  `tas.py`/`qapf.py`, отображение подписи (например, в `toolbar.set_message`),
  обновление при зуме/пане.
- **Точки входа:** `src/charts/built_in/tas.py`, `src/charts/built_in/qapf.py`,
  `_ChartTile` (сообщение тулбара).

## 4. Индикатор множителя зума («×1.2»)

- **Что:** показывать текущий накопленный масштаб плитки.
- **Почему отложено:** низкая ценность; риск рассинхрона с реальными пределами
  (зум можно менять кнопками, колесом, синхронизацией, сбросом).
- **Объём:** малый, но требует единого учёта масштаба. Нужен счётчик/вычисление
  относительно исходных пределов и подпись; сброс/синхронизация должны его
  корректировать.
- **Точки входа:** `_ChartTile._apply_zoom`, `_restore_view`, `apply_synced`.

## 5. Групповой экспорт в многостраничный PDF — СДЕЛАНО

- Реализовано: кнопка «Экспорт всех в PDF» → `MultiChartView.export_all_pdf`
  (`_export_all_pdf_to`), по странице на плитку, экспортируется текущий вид.
- Покрыто smoke-тестом (`PASS export: multi-page PDF with N pages`).
