## 2. Критические уточнения к SPEC (обязательны к исполнению)

Эти пункты **дополняют и уточняют** `CHART_INTERACTIONS_SPEC.md`. При любом расхождении побеждает этот файл + таблица type_id ниже.

### 2.1. Источник `type_id` (один источник истины)

Плитка **никогда** не угадывает тип по title, legend, данным или имени файла.

Допустимые способы (выбрать один и зафиксировать в коде Этапа 1):

- Параметр `set_figure(..., chart_type: str)` — предпочтительно.
- Или атрибут фигуры `fig._minlith_chart_type` (строка), который выставляет рендерер.

Неизвестный `type_id` → **исключение** при сборке сетки (не молчаливый fallback).

### 2.3. `min_range_width`

- Глобальный дефолт: `1e-12`.
- Для `tas` и `sio2_k2o`: не глубже ~25 % от `default_limits` по каждой оси (конкретное число утверждается на Этапе 3 после чтения реальных пределов рендереров). Цель — подписи полей остаются различимыми.

### 2.4. Шаг зума

- Ключ в настройках проекта: `chart.zoom_step` (или ближайший существующий механизм рядом с «Режимом алгоритма»).
- Дефолт: `1.2`.
- Диапазон валидации: `(1.0, 5.0]`. Вне диапазона → откат на `1.2` + warning в лог.
- Плитка и `zoom_math` получают шаг **только параметром**. Сами конфиг не читают.
- Применяется мгновенно ко всем существующим плиткам (без пересоздания).

### 2.5. Модификаторы колеса (уже решено в SPEC)

- Обычное колесо → `zoom_xy` (или разрешённая ось по спецификации).
- `Ctrl` + колесо → `zoom_x`.
- `Ctrl+Shift` + колесо → `zoom_y`.
- `Shift` + колесо → `pan_x`.

Разбор модификаторов — один приватный метод → enum (`ZoomXY | ZoomX | ZoomY | PanX | None`).

### 2.6. Тулбар matplotlib

- Встроенный scroll-zoom **отключён полностью** для всех типов.
- `home` → наш `reset_view`.
- `save` → наш экспорт.
- zoom/pan тулбара дизейблятся (или скрываются) для типов, у которых `rect_zoom=False` / `pan=False`.

### 2.7. Запреты (напоминание, полный список в SPEC §13)

1. Никаких `if chart_type == "pie"` (и любых строковых ветвлений по типу) в `chart_grid.py`.
2. Никаких голых `except: continue` в путях зума.
3. Один обработчик на событие + обязательный `mpl_disconnect` при замене фигуры.
4. Только `draw_idle()`, никогда синхронный `draw()` внутри циклов.
5. Шаг зума — единственная настраиваемая константа взаимодействий.
6. Не расширять `ChartData` ради hover/explode.
7. Не импортировать `pyplot` в новых модулях (кроме существующего `_release_tiles`).
8. Публичные методы (`zoom`, `reset_view`, `render`, `set_figure`, `set_data` …) только расширять.
9. Всё в GUI-потоке, без таймеров/потоков.
10. Smoke-тесты — только синтетические события.

## 3. Архитектурные инварианты (нельзя нарушать)

- `_release_tiles` продолжает закрывать фигуры через `plt.close`.
- Экспорт сохраняет **текущий** вид (зум/пан не сбрасываются).
- `_reflow_tiles` сохраняет зум каждой плитки.
- Всё работает под `QT_QPA_PLATFORM=offscreen`.
- Публичный API `ChartsPage` / `OutputPage` / `build_data_from_results` / `set_data` / `MultiChartView.render` / `columns` не ломается.
