#### Поток расчёта для Types 3-5 (на основе Excel):

```
1. Ab = Na, Or = K
2. Al1 = Al° - Ab, Si1 = Si° - 6*Ab
3. An = f(Ca, Al1, Si1)
4. Illite = min(K/2, al2/6.5, si2/16)     ← K-limited!
5. Chlorite = min(mg/k1, fe/k2, al3/k3, si3/k4)
6. Kn = remaining Al (can be negative!)
7. Q = remaining Si (max(si5, 0))
```

#### Добавлены вспомогательные функции:

- `_calc_an(al1, si1, ca)` — расчёт анортита
- `_calc_kn_gb(al_resid, si_resid)` — расчёт каолинита + гиббсита

## Известные ограничения

1. **Excel ветвления не полностью портированы**: Excel имеет 20+ ветвлений решётки для определения порядка расчёта минералов. Текущая реализация использует упрощённую логику (Ill→Chl→Kn→Q), которая даёт результаты в допусках тестов, но не точно воспроизводит Excel.

2. **Коэффициенты k1-k4**: `calculate_coefficients()` даёт приближённые значения. Точные k-значения для каждого образца определяются в Excel через ветвления.

3. **Stage VI**: Распределение карбонатов/оксидов (Ca, Mg, Fe) упрощено. Excel использует более сложную логику ветвления.

4. **Дефект**: Расчёт дефекта в `calculator.py` использует захардкоженные коэффициенты (`k4=3.494`, `k3=1.469`) вместо актуальных k1-k4.
