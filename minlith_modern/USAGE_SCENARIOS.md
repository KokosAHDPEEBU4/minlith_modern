## 1. GUI (Графический интерфейс)

### 1.1 Запуск

```
python -m src gui
```

### 1.2 Сценарий: Ручной ввод одного образца

```
Старт
  │
  ├── 1. Откройте вкладку «Ввод» (Ctrl+I)
  │     ├── Введите название образца
  │     ├── Заполните таблицу оксидов (SiO₂, Al₂O₃, Fe₂O₃, FeO, MgO, CaO, Na₂O, K₂O, P₂O₅, MnO и др.)
  │     ├── Проверьте сумму (98-102% — синий, <98% — красный, >102% — оранжевый)
  │     └── Нажмите «Рассчитать (F5)»
  │
  ├── 2. Результаты отображаются на вкладке «Результаты» (Ctrl+R)
  │     ├── Сводная таблица: образец, тип, F, A, минералы
  │     ├── Детальная таблица: ФЕ и м.д.% для каждого минерала
  │     └── Цветовая индикация: отрицательные значения = красный
  │
  ├── 3. Экспорт результатов
  │     ├── «Экспорт всех в .xlsx» — кнопка на странице результатов
  │     ├── Ctrl+S — быстрый экспорт (Excel/CSV/JSON)
  │     └── «Экспорт .xlsx» — на странице ввода (последний расчёт)
  │
  └── Конец
```

### 1.3 Сценарий: Пакетный расчёт из файла

```
Старт
  │
  ├── 1. Перейдите на вкладку «Файлы» (Ctrl+E)
  │     ├── Перетащите .xlsx/.csv файл в область drag-drop
  │     │     └── Поддерживаются: .xlsx, .xls, .csv, .zip (рекурсивно)
  │     ├── Или нажмите «Импорт .xlsx» / «Импорт .csv»
  │     │     └── Выберите файлы в диалоге
  │     └── Образцы загружаются в список
  │
  ├── 2. Нажмите на образец в списке (двойной клик)
  │     └── Данные загружаются на страницу «Ввод»
  │
  ├── 3. Нажмите «Рассчитать (F5)»
  │     ├── Расчёт одного образца → результат на странице «Результаты»
  │     └── Для пакетного расчёта:
  │           ├── Загрузите все файлы
  │           ├── Перейдите в код: calculate_batch(samples)
  │           └── Откроется диалог прогресса
  │
  └── Конец
```

## 2. CLI (Командная строка)

### 2.1 Запуск

```
python -m src <команда> [аргументы]
```

### 2.2 Команда: calculate

Расчёт минерального состава из входных файлов.

```
python -m src calculate input.xlsx -o results.xlsx
python -m src calculate input.xlsx --format csv
python -m src calculate input.xlsx --format json
python -m src calculate data1.xlsx data2.csv -o combined.xlsx
python -m src calculate input.zip -o results.xlsx
python -m src calculate input.xlsx --no-cache
```

**Аргументы:**
- `input` — входные файлы (.xlsx, .xls, .csv, .zip)
- `-o, --output` — путь к выходному файлу
- `-f, --format` — формат: xlsx, csv, json, pdf, docx, html
- `--no-cache` — игнорировать кэш

**Ветвление:**
```
calculate
  │
  ├── Файл найден?
  │     ├── Да → Загрузка образцов
  │     │     ├── .xlsx → load_samples()
  │     │     ├── .xls → load_samples() (xlrd)
  │     │     ├── .csv → read_csv() (автоопределение кодировки/разделителя)
  │     │     └── .zip → load_samples_from_zip() (рекурсивно)
  │     │
  │     ├── Кэш активен? (--no-cache не задан)
  │     │     ├── Да (хэш совпадает) → результаты из кэша
  │     │     └── Нет → полный расчёт
  │     │
  │     ├── Расчёт
  │     │     ├── Валидация состава (сумма, NaN, отрицательные)
  │     │     ├── Вычисление коэффициентов (F, A, k1-k4)
  │     │     ├── Классификация типа породы (1-5)
  │     │     ├── Расчёт минералов (стаб)
  │     │     └── Нормализация до 100%
  │     │
  │     ├── Сохранение в БД (SampleRepository)
  │     ├── Сохранение в кэш (ResultCache)
  │     └── Экспорт в формат
  │           ├── xlsx → save_results()
  │           ├── csv → save_results_csv()
  │           ├── json → save_results_json()
  │           └── pdf/docx/html → _export_report()
  │
  └── Файл не найден → ОШИБКА
```

### 2.3 Команда: info

Информация о содержимом файла.

```
python -m src info input.xlsx
python -m src info data1.xlsx data2.csv
```

**Вывод:** количество образцов, названия, состав оксидов.

### 2.4 Команда: validate

Валидация состава оксидов.

```
python -m src validate input.xlsx
```

**Проверки:**
- Сумма оксидов (98-102%)
- Отрицательные значения
- NaN/inf значения

### 2.5 Команда: chart

Построение диаграммы.

```
python -m src chart input.xlsx --type tas -o chart.png
python -m src chart input.xlsx --type "mineral bar" --interactive
python -m src chart input.xlsx --type harker -o harker.html --interactive
python -m src chart input.xlsx --type pie -o pie.png
python -m src chart input.xlsx --type qapf
```

**Аргументы:**
- `input` — входные файлы
- `--type` — тип диаграммы:
  - `bar` / `mineral bar` — столбчатая
  - `pie` — круговая
  - `defect` — дефект
  - `qapf` — QAPF
  - `tas` — TAS
  - `acnk` / `a-cn-k` — аксонометрическая
  - `heatmap` — тепловая карта
  - `rock type` / `rock_type` — типы пород
  - `feldspar` — полевые шпаты
  - `harker` — Харкера
  - `afm` — AFM
  - `sio2_k2o` / `sio2-k2o` — SiO₂-K₂O
  - `bland_altman` — Bland-Altman
  - `correlation` — корреляция
- `-o` — выходной файл (.png, .pdf, .svg, .html)
- `--interactive` — интерактивный режим (Plotly HTML)

**Ветвление:**
```
chart
  │
  ├── Тип диаграммы найден?
  │     ├── Да → Построение
  │     │     ├── --interactive?
  │     │     │     ├── Да → Plotly HTML
  │     │     │     └── Нет → Matplotlib PNG/PDF/SVG
  │     │     └── Экспорт в файл
  │     └── Нет → Список доступных типов
  │
  └── Конец
```

**Аргументы:**
- `input` — входные файлы
- `--template` — шаблон: brief (Краткий), standard (Стандартный), full (Полный)
- `-o` — выходной файл

## 3. Форматы входных данных

```
┌─────────────────────────────────────────────────┐
│ Лист: ИСХ ДАННЫЕ                                │
│ Строка 1: Заголовки (название образца)           │
```

## 5. База данных

### 5.1 Хранение

```
~/.minlith/data/minlith.db
├── samples — образцы (id, name, created_at)
├── calculations — расчёты (sample_id, rock_type, F, A, minerals...)
└── version_tracking — отслеживание версий (file_hash, version, updated_at)
```

### 5.2 Операции

- `save_result(result)` — сохранение результата
- `get_recent_results(limit)` — последние N записей
- `search_samples(query)` — поиск по имени
- `delete_sample(id)` — удаление образца
- `cleanup_old_records(keep_last)` — очистка старых записей
- `get_stats()` — статистика (образцы, расчёты, диски)

### 5.3 Кэширование

```
~/.minlith/cache/
├── index.json — индекс кэша (SHA-256 хэш → файл)
└── <hash>.json — результаты расчёта
```

- Ключ: SHA-256 хэш входного файла
- Инвалидация: при изменении файла
- Флаг `--no-cache` для полного пересчёта

## 7. Ошибки и восстановление

### 7.1 Классификация ошибок

| Тип | Пример | Действие |
|---|---|---|
| Критическая | Файл не найден | Сообщение + выход |
| Расчёта | Division by zero | Fallback значение |
| Ввода | NaN в оксидах | Предупреждение |
| Экспорта | Нет прав на запись | Сообщение |
| БД | Повреждён SQLite | Пересоздание |

### 7.2 Пользовательские сообщения (ru)

```python
USER_MESSAGES = {
```

## 9. Типы пород (rock_type)
