## Методология оценки

Каждая диаграмма оценивается по четырём критериям:

| Критерий | Описание | Шкала |
|----------|----------|-------|
| **Релевантность** | Насколько диаграмма полезна для интерпретации результатов MINLITH | 1-5 |
| **Реализуемость** | Сложность реализации (данные, алгоритмы, границы полей) | 1-5 |
| **Востребованность** | Насколько часто геологи используют эту диаграмму в практике | 1-5 |
| **Уникальность** | Даёт ли диаграмма информацию, которую не дают другие | 1-5 |

**Решение:**
- ✅ **Включить** — сумма ≥ 14, релевантность ≥ 3
- ⚠️ **Опционально** — сумма 10-13
- ❌ **Не включать** — сумма < 10

## Раздел 1. Классификационные диаграммы (основные)

### 1.1. QAPF — Классификация магматических пород (плутонические)

**Описание:** Треугольник кварц (Q) — щелочные полевые шпаты (A) — плагиоклаз (P). Стандарт IUGS для классификации глубинных магматических пород.

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 5 | Прямое использование результатов MINLITH (Q, Ab, An, Or) |
| Реализуемость | 3 | Треугольник matplotlib, границы полей из IUGS |
| Востребованность | 5 | Стандарт петрологии, используется повсеместно |
| Уникальность | 4 | Нет аналогов среди других диаграмм |
| **Сумма** | **17** | |

**Почему включить:**
- MINLITH рассчитывает все компоненты QAPF (Q, Ab, An, Or) — данные готовы
- Стандарт IUGS, обязателен для научных публикаций
- Позволяет классифицировать породу по нормативному составу
- Пользователи MINLITH явно ожидают эту диаграмму

**Почему может быть сложно:**
- Нужно корректно вычислять Q, A, P, F из нормативных минералов
- Границы полей — сложные полигоны (не линейные)
- Различия между плутоническими и вулканическими вариантами

**Решение:** ✅ **Включить (базовая, приоритет 1)**

---

### 1.2. TAS — Total Alkali–Silica (вулканические породы)

**Описание:** Диаграмма SiO₂ vs Na₂O+K₂O. Классификация вулканических пород по химическому составу. Стандарт IUGS (Le Maitre et al., 2005).

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 5 | Использует исходные оксиды (SiO₂, Na₂O, K₂O) |
| Реализуемость | 4 | Простой scatter plot, границы полей из литературы |
| Востребованность | 5 | Наиболее распространённая диаграмма для вулканитов |
| Уникальность | 3 | Многие программы умеют TAS |
| **Сумма** | **17** | |

**Почему включить:**
- Данные уже есть (исходные оксиды), никаких расчётов не нужно
- Стандарт де-факто для вулканических пород
- Разделение на щелочной/субщелочной ряд (линия Irvine & Baragar)
- Полезна даже без нормативного расчёта

**Почему может быть сложно:**
- Много полей (15+), границы — сложные кривые
- Нужна нормализация к 100% без летучих
- Различия между версиями (Le Maitre 1989 vs Middlemost 1994)

**Решение:** ✅ **Включить (базовая, приоритет 1)**

---

### 1.3. A-CN-K — Ветеринг/происхождение осадочных пород

**Описание:** Треугольник Al₂O₃–(CaO+Na₂O)–K₂O (в мол. %). Используется для оценки степени выветривания и типа протолита.

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 4 | Использует исходные оксиды, MINLITH рассчитывает глинистые |
| Реализуемость | 3 | Треугольник, границы полей из Nesbitt & Young (1984) |
| Востребованность | 4 | Стандарт для осадочных пород и палеопочв |
| Уникальность | 4 | Даёт информацию о выветривании, которую не дают другие |
| **Сумма** | **15** | |

**Почему включить:**
- Позволяет оценить степень химического выветривания (индекс CIA)
- Различает гранитный протолит, базальтовый протолит, андезитовый
- Полезна для осадочных пород (песчаники, глины)
- Данные уже есть (исходные оксиды)

**Почему может быть сложно:**
- Нужна коррекция CaO (только силикатный CaO, без карбонатного)
- Границы полей — эмпирические, разные авторы дают разные версии
- Менее известна среди "классических" петрологов

**Решение:** ✅ **Включить (базовая, приоритет 2)**

---

### 1.4. A-F-M — Метаморфические породы (Jensen, 1976)

**Описание:** Треугольник Al–(Fe+Ti)–Mg (в мол. %). Классификация метаморфических и магматических пород.

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 3 | Использует исходные оксиды, но MINLITH ориентирован на осадочные/изменённые |
| Реализуемость | 3 | Треугольник, границы из Jensen (1976) |
| Востребованность | 3 | Чаще используется для магматических и метаморфических |
| Уникальность | 3 | Пересекается с QAPF по функциональности |
| **Сумма** | **12** | |

**Почему включить:**
- Полезна для метаморфических пород (шисты, гнейсы)
- Различает толеитовый и кальц-щелочной ряды
- Данные уже есть

**Почему может быть не нужна:**
- Целевая аудитория MINLITH — в основном осадочные/изменённые породы
- QAPF и TAS покрывают большинство задач классификации
- Меньше распространена в русскоязычной литературе

**Решение:** ⚠️ **Опционально (приоритет 3, можно добавить позже)**

## Раздел 2. Дискриминационные диаграммы (тектонические обстановки)

### 2.1. Pearce — Ti vs Zr / Zr vs Y / Nb–Y–Zr

**Описание:** Диаграммы для определения тектонической обстановки (MORB, внутриплитные, дуговые).

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 2 | Требуются микроэлементы (Zr, Y, Nb), которых нет в MINLITH |
| Реализуемость | 2 | Простые scatter plot, но данных нет |
| Востребованность | 4 | Широко используются в петрологии |
| Уникальность | 3 | Уникальная информация, но данные отсутствуют |
| **Сумма** | **11** | |

**Почему включить:**
- Очень полезны для магматических пород
- Стандартные диаграммы Pearce (1982, 1983)

**Почему НЕ включать:**
- MINLITH работает только с основными оксидами (18 штук)
- Микроэлементы (Zr, Y, Nb, Ta, Hf) не входят в исходные данные
- Расширение списка оксидов — изменение всей архитектуры
- Можно добавить позже как "пользовательскую" диаграмму

**Решение:** ❌ **Не включать в базовый набор** (но оставить возможность через плагины)

### 2.2. SiO₂–K₂O (Peccerillo & Taylor, 1976)

**Описание:** Бинарная диаграмма для разделения толеитовой, кальц-щелочной и щелочной серий.

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 4 | Использует SiO₂ и K₂O — данные есть |
| Реализуемость | 5 | Простой scatter plot с линиями-границами |
| Востребованность | 4 | Часто используется для магматических серий |
| Уникальность | 2 | Пересекается с TAS по функциональности |
| **Сумма** | **15** | |

**Почему включить:**
- Простая и понятная диаграмма
- Данные уже есть
- Полезна для разделения серий вулканитов

**Почему может быть не нужна:**
- TAS уже показывает ту же информацию (щелочность vs силикатность)
- Меньше полей, чем TAS, меньше информативности
- Перекрывается с TAS

**Решение:** ⚠️ **Опционально (приоритет 3)**

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 5 | Прямое отображение результатов MINLITH |

| **Сумма** | **17** | |

**Почему включить:**
- Основной способ визуализации результатов нормативного расчёта

## Раздел 5. Специализированные диаграммы

### 5.1. CIA (Chemical Index of Alteration)

**Описание:** Индекс CIA = 100 × Al₂O₃ / (Al₂O₃ + CaO* + Na₂O + K₂O). Оценка степени химического выветривания.

| Критерий | Оценка | Обоснование |
|----------|--------|-------------|
| Релевантность | 4 | Использует исходные оксиды |
| Реализуемость | 5 | Одна формула на образец |
| Востребованность | 4 | Стандарт для осадочных пород и палеопочв |
| Уникальность | 3 | Можно вычислить вручную |
| **Сумма** | **16** | |

**Почему включить:**
- Простая числовая характеристика
- Полезна для осадочных пород (основной профиль MINLITH)
- Можно показывать как дополнительный столбец в таблице результатов
- Не требует отдельной диаграммы (можно интегрировать в таблицу)

**Почему может быть не нужна:**
- Это не диаграмма, а числовой индекс
- Можно добавить как столбец в таблицу результатов

**Решение:** ✅ **Включить как параметр (не как отдельную диаграмму)**

| **Сумма** | **15** | |

**Почему может быть не нужна:**

**Решение:** ✅ **Включить как параметр (не как отдельную диаграмму)**

### Интерфейс плагина

```python
class ChartPlugin(ABC):
    @abstractmethod
    def get_name(self) -> str: ...

    @abstractmethod
    def get_description(self) -> str: ...

    @property
    @abstractmethod
    def requires_minerals(self) -> bool: ...

    @property
    @abstractmethod
    def requires_oxides(self) -> bool: ...

    @abstractmethod
    def render(self, data: ChartData, engine: str = "matplotlib", **kwargs) -> Figure: ...

    @abstractmethod
    def export(self, data: ChartData, path: Path, format: str = "png", **kwargs): ...
```

## Заключение

### Рекомендуемый план реализации:

1. **Сначала** — 6 базовых диаграмм (MVP): столбчатая, QAPF, TAS, defect, pie, A-CN-K
2. **Затем** — опциональные: тепловая карта, типы пород, треугольник полевых шпатов
3. **Позже** — через плагиновую систему: Harker, AFM, карбонатная, Bland-Altman
4. **Не реализовывать** — требующие микроэлементов (Pearce, spider) или 3D/ML (PCA)

### Ключевое правило:

> **Если диаграмма требует данных, которых нет в MINLITH — она реализуется только через плагиновую систему, не в базовом наборе.**

Это сохраняет фокус на нормативном минералогическом расчёте и не размывает продукт.
